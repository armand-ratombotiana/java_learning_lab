## 1. Java

**Path:** [`labs/java/`](labs/java/)

**Coverage:** Complete Java ecosystem from syntax to JVM internals — data types, control flow, OOP, inheritance, polymorphism, interfaces, exceptions, generics, collections, streams, lambdas, functional programming, concurrency, virtual threads, I/O & NIO, annotations, reflection, Java 21+ features, records, sealed classes, pattern matching, Optional, date/time API, strings, enums, modules, JVM internals, testing, networking, security, logging, serialization, reactive programming, performance profiling, memory model, build tools, best practices, class loading & bytecode, JIT, GC, JVM tuning, structured concurrency, off-heap memory, object layout, advanced concurrency, performance antipatterns.

**Labs:** 52 core + 16 deep-dive modules (~100+ micro-labs)

**Deep-dive sub-academies:**
- `collections-deep/` · `concurrency-deep/` · `jvm-deep/` · `memory-deep/`
- `modern-java-deep/` · `performance-deep/` · `serialization-deep/` · `networking-deep/`
- `testing-deep/` · `reactive-deep/` · `java-io-nio-deep/` · `java-module-foreign/`
- `java-records-sealed-patterns/` · `java-reflection-annotations/` · `java-streams-optional/`
- `java-version-evolution/`

**Extras:** Jakarta EE sub-academy, `LEETCODE_SOLUTIONS/` (22 solutions: collections, concurrency, streams, design patterns, JVM, testing), 10+ interview guides (Amazon, Google, Meta, Microsoft, Apple, Netflix, Oracle, JVM), `JAVA_CODING_TEMPLATES.md`, `INTERVIEW_CHEATSHEET.md`.

## Notes

- **Interview guides:** Nearly every academy ships company-targeted interview guides (Amazon, Google, Meta, Microsoft, Apple, Netflix, Oracle, etc.) plus `ACADEMY_INTERVIEW_GUIDE.md`, `COMPANY_INTERVIEW_GUIDE.md`, `COMPANY_BEHAVIORAL_GUIDE.md`, and `CRACKING_THE_INTERVIEW_GUIDE.md`.
- **Shared assets:** `LEETCODE_PATTERN_CHEATSHEET.md`, `NEETCODE_ROADMAP.md`, `SYSTEM_DESIGN_CHEATSHEET.md` appear across most academies.
- **Naming:** The production-scenarios academy lives in the directory `real-production-scenarios/` (not `production-scenarios/`).
- **Root-level content:** The repo root also contains legacy module directories (`01-core-java/`, `02-spring-ecosystem/`, `23-observability/` … `59-webassembly/`), a root `capstones/`, and `java-master-lab/` — see `README.md` and `MODULE_INVENTORY.md`.
