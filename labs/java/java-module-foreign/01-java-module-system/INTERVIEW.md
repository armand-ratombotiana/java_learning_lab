# Interview Questions: Java Module System

## Basic
1. What is a Java module and what problem does JPMS solve?
2. What is a `module-info.java` file?
3. What is the difference between `exports` and `opens`?

## Intermediate
4. What does `requires transitive` do?
5. How do you declare a compile-only dependency?
6. What are automatic modules and how do they work?

## Advanced
7. Explain the difference between the module path and the classpath.
8. How does the `ServiceLoader` mechanism work with modules?
9. What is a qualified export and when would you use it?
10. How do you migrate a classpath-based project to modules?

## Expert
11. What is the unnamed module and what limitations does it have?
12. How does `--add-exports` differ from `--add-opens`?
13. What happens at module resolution time? How does the JVM resolve module graphs?
14. How do layered modules work in application servers (e.g., Jakarta EE)?
