# 04 — Bytecode Manipulation

## Overview
ASM, ByteBuddy, class transformation, runtime code generation.

## Learning Objectives
- Understand class file structure and bytecode instruction set
- Use ASM for reading and writing bytecode
- Use ByteBuddy for higher‑level class generation
- Apply runtime code generation for proxies, mocks, and interception

## Prerequisites
- Java 21+
- Reflection and proxy pattern knowledge
