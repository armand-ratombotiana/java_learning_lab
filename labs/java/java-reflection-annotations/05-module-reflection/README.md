# 05 — Module Reflection

## Overview
Module reflection, add‑opens, add‑exports, module‑layer APIs.

## Learning Objectives
- Understand Java 9 module system basics
- Use `Module`, `ModuleDescriptor`, and `Layer` APIs
- Open packages for reflective access at runtime
- Work with module layers and custom class loaders

## Prerequisites
- Java 21+
- Reflection basics (lab 01)
- Module system fundamentals
