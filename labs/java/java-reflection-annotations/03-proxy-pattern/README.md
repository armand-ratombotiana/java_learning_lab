# 03 — Proxy Pattern

## Overview
Dynamic proxies, InvocationHandler, ProxyGenerator, use cases (AOP, caching).

## Learning Objectives
- Understand `java.lang.reflect.Proxy` and `InvocationHandler`
- Create dynamic proxies for interface‑based targets
- Implement cross‑cutting concerns (logging, caching, transactions)
- Understand proxy generation internals

## Prerequisites
- Java 21+
- Reflection basics (lab 01)
