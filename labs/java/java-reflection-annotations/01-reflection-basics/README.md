# 01 — Reflection Basics

## Overview
Class object, constructor/method/field reflection, dynamic invocation, access checks.

## Learning Objectives
- Obtain Class objects via `.class`, `getClass()`, `Class.forName()`
- Reflect constructors, methods, and fields at runtime
- Dynamically invoke methods and access fields, including private members
- Understand access checks and `setAccessible()`

## Prerequisites
- Java 21+
- Basic OOP and inheritance concepts
