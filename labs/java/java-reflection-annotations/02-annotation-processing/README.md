# 02 — Annotation Processing

## Overview
Custom annotations, retention policies, runtime processing, annotation processors.

## Learning Objectives
- Declare custom annotations with `@interface`
- Understand `@Retention`, `@Target`, `@Documented`, `@Inherited`
- Process annotations at runtime via reflection
- Write compile‑time annotation processors with `javax.annotation.processing`

## Prerequisites
- Java 21+
- Reflection basics (lab 01)
