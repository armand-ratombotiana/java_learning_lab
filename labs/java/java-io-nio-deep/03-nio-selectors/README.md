# NIO Selectors Deep Dive

## Overview
Non-blocking I/O, Selector, SelectionKey, Reactor pattern

## Learning Objectives
- Understand the Selector-based event-driven I/O model
- Implement non-blocking I/O with Selector and SelectionKey
- Apply the Reactor pattern for scalable networking
- Analyze performance characteristics of select() vs blocking I/O

## Prerequisites
- Java 21+
- Understanding of NIO Channels
- Familiarity with networking fundamentals

## Lab Structure
This micro-lab follows the standard pedagogical structure for hands-on learning.

## Quick Start
1. Navigate to the source directory: `src/main/java/com/java/io/nio/lab03/`
2. Review the main implementation class
3. Compile and run the echo server example
4. Complete the exercises
