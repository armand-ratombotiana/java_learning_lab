# File Visitor & Watcher Deep Dive

## Overview
Files.walkFileTree, WatchService, SimpleFileVisitor, directory monitoring

## Learning Objectives
- Understand file tree traversal with Files.walkFileTree
- Implement custom SimpleFileVisitor for recursive operations
- Use WatchService for directory change monitoring
- Apply file visitor patterns for search, copy, and cleanup

## Prerequisites
- Java 21+
- Basic understanding of NIO.2 file API
- Familiarity with the filesystem API

## Lab Structure
This micro-lab follows the standard pedagogical structure for hands-on learning.

## Quick Start
1. Navigate to the source directory: `src/main/java/com/java/io/nio/lab05/`
2. Review the main implementation class
3. Compile and run examples
4. Complete the exercises
