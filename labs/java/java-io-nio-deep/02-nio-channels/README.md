# NIO Channels Deep Dive

## Overview
FileChannel, SocketChannel, ServerSocketChannel, scatter/gather, memory-mapped files

## Learning Objectives
- Understand NIO Channel architecture and how they differ from I/O streams
- Implement FileChannel for high-performance file I/O
- Use SocketChannel/ServerSocketChannel for non-blocking networking
- Apply scatter/gather operations for efficient buffer management
- Leverage memory-mapped files for ultra-fast I/O

## Prerequisites
- Java 21+
- Basic understanding of I/O streams
- Familiarity with byte buffers

## Lab Structure
This micro-lab follows the standard pedagogical structure for hands-on learning.

## Quick Start
1. Navigate to the source directory: `src/main/java/com/java/io/nio/lab02/`
2. Review the main implementation class
3. Compile and run examples
4. Complete the exercises
