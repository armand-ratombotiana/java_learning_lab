# I/O Streams Deep Dive

## Overview
FileInputStream/OutputStream, Buffered streams, Data streams, Pushback, Sequence streams

## Learning Objectives
- Understand the hierarchy of Java I/O streams (InputStream, OutputStream, Reader, Writer)
- Implement working code with FileInputStream/OutputStream
- Analyze buffering performance and trade-offs
- Apply Data streams for primitive type serialization
- Use Pushback and Sequence streams for advanced parsing

## Prerequisites
- Java 21+
- Basic understanding of file I/O
- Familiarity with the decorator pattern

## Lab Structure
This micro-lab follows the standard pedagogical structure for hands-on learning.

## Quick Start
1. Navigate to the source directory: `src/main/java/com/java/io/nio/lab01/`
2. Review the main implementation class
3. Compile and run examples to see I/O stream behavior
4. Complete the exercises to cement understanding
