# Lab 03: Pattern Matching Deep Dive

## Overview
Pattern matching in Java has evolved from `instanceof` to a rich feature including type patterns, record patterns, guarded patterns (`when` clauses), and nested pattern matching. This lab explores the full landscape.

## Goals
- Use type patterns with `instanceof` and `switch`
- Destructure records with record patterns
- Combine nested record patterns
- Use `when` clauses for guarded patterns
- Handle `null` in pattern matching

## Prerequisites
- Java 21+
- Familiarity with records and sealed classes
- Basic switch expressions
