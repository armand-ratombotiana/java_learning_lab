# Interview Questions: Pattern Matching

## Basic
1. What is a type pattern in Java?
2. How does flow-sensitive scoping work for pattern variables?
3. What is the difference between `switch` as a statement and `switch` as an expression?

## Intermediate
4. How do record patterns differ from type patterns?
5. What happens if you put a more general pattern before a specific one in a switch?
6. How do you handle `null` with pattern matching in switch?

## Advanced
7. Explain guarded patterns and the `when` clause. When would you use one?
8. Can you use pattern matching with generic records? What are the limitations?
9. How does the compiler determine exhaustiveness in a pattern switch?
10. What is the dominance rule and how does the compiler enforce it?

## Expert
11. How does pattern matching interact with sealed class hierarchies?
12. Can pattern variables be used in lambda expressions? Explain the capture restrictions.
13. How does the compiler translate nested record patterns to bytecode?
14. What are the future directions for pattern matching in Java (deconstruction patterns for classes)?
