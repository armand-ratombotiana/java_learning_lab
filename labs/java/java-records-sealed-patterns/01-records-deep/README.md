# Lab 01: Records Deep Dive

## Overview
Java Records (introduced in Java 14 as preview, finalized in Java 16) provide a compact syntax for declaring data carriers. This deep-dive lab explores advanced use cases: record patterns, compact constructors, local records, and using records with JPA/Hibernate.

## Goals
- Understand record patterns in switch and instanceof
- Implement compact constructors for validation and normalization
- Create local records within methods for scoped data grouping
- Use records as DTOs with JPA entities
- Master record serialization and deserialization

## Prerequisites
- Java 21+
- Familiarity with basic records (Java 16+)
- Basic JPA/Hibernate knowledge
- Understanding of pattern matching basics
