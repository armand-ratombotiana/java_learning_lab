# Interview Questions: Java Records Deep Dive

## Basic
1. What is a record in Java and what problem does it solve?
2. How do records differ from traditional classes?
3. Can a record extend another class? Can it implement interfaces?

## Intermediate
4. What is a compact constructor and when would you use one?
5. How do record patterns work with `instanceof` and `switch`?
6. Can records be used with JPA? What are the limitations?

## Advanced
7. Explain how records handle serialization differently from regular classes.
8. How do local records improve encapsulation within a method?
9. What happens when a record component is an array or mutable object?
10. How does the canonical constructor protect against deserialization attacks?

## Expert
11. Can you create a record with a variable number of components (varargs)?
12. How are records implemented at the bytecode level?
13. What is the `Record` superclass and what methods does it provide?
14. Can records participate in inheritance hierarchies via sealed interfaces?
