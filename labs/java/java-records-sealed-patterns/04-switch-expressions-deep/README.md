# Lab 04: Switch Expressions Deep Dive

## Overview
Switch expressions (standard in Java 14) with arrow syntax, yield, and exhaustiveness checks. This lab covers arrow syntax, exhaustive switch, null handling, and pattern-rich switch blocks.

## Goals
- Master arrow (`->`) syntax vs colon (`:`) syntax
- Use `yield` to return values from multi-line blocks
- Write exhaustive switch expressions
- Handle `null` explicitly in switch
- Combine switch expressions with patterns and `when` clauses

## Prerequisites
- Java 21+
- Pattern matching basics
- Understanding of sealed types
