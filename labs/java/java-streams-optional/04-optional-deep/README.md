# 04 — Optional Deep

## Overview
Optional patterns, orElseThrow, or, stream(), map/flatMap, OptionalInt/Long/Double.

## Learning Objectives
- Use `Optional<T>` effectively: `map`, `flatMap`, `filter`, `orElse`, `orElseGet`
- Understand `orElseThrow()` (Java 10+) and its `@NotNull` guarantee
- Convert between `Optional` and `Stream` with `stream()` (Java 9+)
- Use `OptionalInt`, `OptionalLong`, `OptionalDouble` for primitives

## Prerequisites
- Java 21+
- Lambda and method reference fluency
