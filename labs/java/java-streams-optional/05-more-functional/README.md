# 05 — More Functional

## Overview
Function composition, currying, memoization, functional interfaces deep.

## Learning Objectives
- Chain functions with `compose()` and `andThen()`
- Implement currying and partial application
- Cache function results with memoization patterns
- Understand `Function`, `BiFunction`, `UnaryOperator`, `Supplier`, `Consumer` in depth

## Prerequisites
- Java 21+
- Lambda and method reference familiarity
