# 02 — Stream Collectors

## Overview
Custom Collector, groupingBy, partitioningBy, teeing, toMap.

## Learning Objectives
- Use built‑in `Collectors` (toList, toSet, toMap, joining, summarizingInt)
- Create custom `Collector` implementations
- Use `groupingBy`, `partitioningBy`, `teeing`, `toMap` with conflict resolution

## Prerequisites
- Java 21+
- Stream pipeline concepts (lab 01)
