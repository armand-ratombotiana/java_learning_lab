# 03 — Parallel Streams

## Overview
ForkJoinPool, spliterator, thread safety, performance considerations.

## Learning Objectives
- Understand how parallel streams use `ForkJoinPool.commonPool()`
- Identify when parallelism improves performance
- Avoid thread‑safety pitfalls with shared mutable state
- Use `Spliterator` for custom splitting strategies

## Prerequisites
- Java 21+
- Stream pipeline and collector knowledge
