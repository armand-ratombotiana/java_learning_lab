# 01 — Stream Pipeline

## Overview
Stream sources, intermediate/terminal ops, lazy evaluation, ordering.

## Learning Objectives
- Create streams from collections, arrays, generators, files
- Chain intermediate operations (filter, map, flatMap, distinct, sorted, peek)
- Understand terminal operations (collect, forEach, reduce, count, anyMatch)
- Explain lazy evaluation and stream pipeline execution order

## Prerequisites
- Java 21+
- Lambda expressions and functional interfaces
