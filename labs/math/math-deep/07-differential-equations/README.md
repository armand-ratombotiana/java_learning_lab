# Differential Equations

## Overview
This micro-lab covers **Differential Equations**, including ODE solving (Euler, Runge-Kutta), PDE concepts, and separation of variables. Essential for physics simulation, engineering modeling, financial mathematics, and scientific computing.

## Topics Covered
- Ordinary Differential Equations (ODEs): first-order, second-order, systems
- Euler's method and improved Euler (Heun's method)
- Runge-Kutta methods: RK4, adaptive step size
- Partial Differential Equations (PDEs): heat, wave, Laplace equations
- Separation of variables for PDEs

## Learning Objectives
1. Solve first-order ODEs using Euler's method
2. Implement the classical fourth-order Runge-Kutta (RK4) method
3. Apply adaptive step size control for stiff equations
4. Understand PDE classification (elliptic, parabolic, hyperbolic)
5. Implement finite difference methods for simple PDEs
