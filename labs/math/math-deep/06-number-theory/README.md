# Number Theory

## Overview
This micro-lab covers **Number Theory**, including primality testing, GCD, modular arithmetic, Chinese Remainder Theorem, and Euler's totient function. Foundational for cryptography, coding theory, and algorithm design.

## Topics Covered
- Primality testing (trial division, Miller-Rabin, AKS)
- Euclidean algorithm for GCD and extended GCD
- Modular arithmetic: addition, multiplication, exponentiation, inverses
- Chinese Remainder Theorem for simultaneous congruences
- Euler's totient function φ(n) and properties

## Learning Objectives
1. Implement Miller-Rabin probabilistic primality test
2. Compute GCD using Euclid's algorithm and extended GCD for modular inverses
3. Perform fast modular exponentiation
4. Apply Chinese Remainder Theorem to solve congruence systems
5. Compute Euler's totient and understand its role in RSA
