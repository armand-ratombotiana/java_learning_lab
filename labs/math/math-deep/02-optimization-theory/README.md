# Optimization Theory

## Overview
This micro-lab explores **Optimization Theory**, including convex optimization, Lagrange multipliers, gradient descent, Newton's method, and constrained optimization. Foundational for machine learning training, operations research, and engineering design.

## Topics Covered
- Convex sets and functions, convexity conditions
- Unconstrained optimization: gradient descent, Newton's method
- Constrained optimization: Lagrange multipliers, KKT conditions
- Duality theory, primal-dual relationships

## Learning Objectives
1. Determine convexity of functions and optimization problems
2. Implement gradient descent with various learning rate schedules
3. Apply Lagrange multipliers to equality-constrained problems
4. Solve constrained problems using KKT conditions
5. Implement Newton's method for unconstrained optimization
