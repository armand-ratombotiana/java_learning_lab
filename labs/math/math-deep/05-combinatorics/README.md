# Combinatorics

## Overview
This micro-lab covers **Combinatorics**, including permutations, combinations, generating functions, inclusion-exclusion principle, and recurrence relations. Essential for algorithm analysis, probability theory, discrete mathematics, and combinatorial optimization.

## Topics Covered
- Permutations (with/without repetition) and combinations
- Binomial theorem and binomial coefficients
- Inclusion-exclusion principle
- Generating functions (ordinary, exponential)
- Recurrence relations and characteristic equations

## Learning Objectives
1. Compute permutations and combinations with efficient algorithms
2. Apply inclusion-exclusion to counting problems with overlapping constraints
3. Use generating functions to solve combinatorial enumeration
4. Solve recurrence relations using characteristic equations
5. Implement combinatorial algorithms for real-world problems
