# Information Theory

## Overview
This micro-lab covers **Information Theory**, including entropy, mutual information, channel capacity, source coding, and Shannon's theorems. Foundational for data compression, communication systems, machine learning, and cryptography.

## Topics Covered
- Shannon entropy and joint/conditional entropy
- Mutual information and Kullback-Leibler divergence
- Channel capacity: binary symmetric channel, AWGN
- Source coding: Huffman codes, Shannon-Fano coding
- Shannon's source coding and channel coding theorems

## Learning Objectives
1. Compute entropy, joint entropy, and conditional entropy from probability distributions
2. Calculate mutual information and understand its role in feature selection
3. Determine channel capacity for discrete memoryless channels
4. Implement Huffman coding for optimal prefix-free compression
5. Apply Shannon's theorems to understand fundamental limits of compression and communication
