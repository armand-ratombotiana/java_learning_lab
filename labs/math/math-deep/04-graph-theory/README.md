# Graph Theory

## Overview
This micro-lab explores **Graph Theory**, covering graph properties, isomorphism, Eulerian/Hamiltonian paths, planar graphs, and graph coloring. Foundational for network analysis, routing algorithms, circuit design, and social network modeling.

## Topics Covered
- Graph representations: adjacency matrix, adjacency list, edge list
- Graph isomorphism and invariants
- Eulerian and Hamiltonian paths and cycles
- Planar graphs and Kuratowski's theorem
- Vertex and edge coloring, chromatic number

## Learning Objectives
1. Implement graph representations and basic traversals (BFS, DFS)
2. Detect graph isomorphism using degree sequences and invariants
3. Find Eulerian paths using Hierholzer's algorithm
4. Determine planarity using Kuratowski's theorem
5. Solve graph coloring problems with greedy and backtracking algorithms
