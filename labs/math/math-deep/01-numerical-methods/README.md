# Numerical Methods

## Overview
This micro-lab provides a deep-dive exploration of **Numerical Methods**, covering root finding, Newton-Raphson, numerical integration (trapezoidal, Simpson), and numerical differentiation. Essential for scientific computing, engineering simulation, and machine learning optimization.

## Topics Covered
- Root finding: bisection, secant, Newton-Raphson
- Numerical integration: trapezoidal rule, Simpson's rule, adaptive quadrature
- Numerical differentiation: forward/central/backward difference, Richardson extrapolation
- Error analysis, convergence rates, stability

## Learning Objectives
1. Implement Newton-Raphson and bisection root-finding algorithms
2. Compute definite integrals using trapezoidal and Simpson's rules
3. Approximate derivatives using finite difference methods
4. Analyze numerical stability and error propagation
5. Apply methods to real-world scientific computing problems
