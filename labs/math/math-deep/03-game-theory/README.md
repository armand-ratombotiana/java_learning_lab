# Game Theory

## Overview
This micro-lab covers **Game Theory**, including Nash equilibrium, zero-sum games, minimax theorem, Prisoner's dilemma, and payoff matrices. Essential for economics, AI decision-making, multi-agent systems, and auction design.

## Topics Covered
- Normal-form and extensive-form games
- Nash equilibrium existence and computation
- Zero-sum games and the minimax theorem
- Iterated games, cooperation, and Prisoner's dilemma
- Mixed strategies and mixed Nash equilibrium

## Learning Objectives
1. Model strategic interactions using payoff matrices
2. Compute pure and mixed Nash equilibria
3. Implement minimax for zero-sum games
4. Analyze Prisoner's dilemma and iterated game strategies
5. Apply game theory to AI and multi-agent systems
