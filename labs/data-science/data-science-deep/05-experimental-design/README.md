# Experimental Design

## Overview
Principles and implementation of statistical experimental design. Covers blocking, factorial designs, randomization, sample size determination, and analysis of variance.

## Learning Objectives
1. Design randomized controlled experiments with blocking
2. Implement full and fractional factorial designs (2^k, 2^(k-p))
3. Apply randomization and blocking to reduce variance
4. Analyze experiments using ANOVA
5. Construct response surface designs
6. Understand efficiency and optimality criteria
