# Statistical Power Analysis

## Overview
Methods for power analysis, effect size estimation, and sample size calculation across common statistical tests. Covers t-test, ANOVA, chi-square, proportion tests, and equivalence testing.

## Learning Objectives
1. Compute statistical power for common tests given sample size and effect size
2. Calculate required sample size for desired power
3. Estimate effect sizes (Cohen's d, f, w, h)
4. Create power curves across sample sizes
5. Understand the relationship between α, β, effect size, and sample size
6. Apply power analysis to experimental design
