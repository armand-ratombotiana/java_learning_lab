## How to Use

Each micro-lab contains:
- **README.md** — Overview and learning objectives
- **GUIDE.md** — Detailed tutorial with Java code examples
- **INTERVIEW.md** — FAANG interview questions
- **PROBLEM_WALKTHROUGH.md** — Step-by-step coding walkthrough
- **MOCK_INTERVIEW.md** — Mock interview transcript
- **src/** — Java source files (package `com.datascience.deep.lab0X`, Java 21+)

Complete labs sequentially or jump to topics of interest. Each lab is self-contained.
