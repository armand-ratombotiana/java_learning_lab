# A/B Testing Framework

## Overview
Statistical hypothesis testing framework for randomized experiments. Covers sample size determination, significance testing, power analysis, and metric design for online controlled experiments.

## Learning Objectives
1. Design and analyze A/B tests with proper statistical methodology
2. Calculate required sample sizes for desired power and effect size
3. Implement hypothesis tests (z-test, t-test) for conversion and continuous metrics
4. Apply multiple testing corrections (Bonferroni, Benjamini-Hochberg)
5. Understand variance reduction techniques (CUPED, stratified allocation)
6. Detect and handle peeking and Simpson's paradox
