# Model Interpretation

## Overview
Techniques for interpreting machine learning model predictions. Covers SHAP (SHapley Additive exPlanations), LIME (Local Interpretable Model-agnostic Explanations), permutation importance, partial dependence plots, and feature interaction detection.

## Learning Objectives
1. Compute SHAP values for model predictions using Kernel SHAP
2. Implement LIME for local explanations
3. Calculate permutation feature importance
4. Generate partial dependence and ICE plots
5. Detect feature interactions (Friedman's H-statistic)
6. Build an interpretable model inspection dashboard
