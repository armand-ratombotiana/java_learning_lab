# Causal Inference Methods

## Overview
Techniques for estimating causal effects from observational data when randomized experiments are infeasible. Covers propensity score matching, difference-in-differences, instrumental variables, and sensitivity analysis.

## Learning Objectives
1. Understand the potential outcomes framework (Rubin Causal Model)
2. Implement propensity score matching and weighting (IPTW)
3. Apply difference-in-differences with parallel trends assumption
4. Use instrumental variables for endogenous treatments
5. Conduct sensitivity analysis (Rosenbaum bounds)
6. Compare structural vs reduced-form causal estimation
