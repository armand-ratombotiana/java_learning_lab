# ML Pipeline Automation

## Overview
Automated machine learning pipeline construction covering feature selection, model selection, hyperparameter tuning, ensembling, and cross-validation orchestration.

## Learning Objectives
1. Build an automated feature selection pipeline (filter, wrapper, embedded)
2. Implement hyperparameter tuning (grid search, random search, Bayesian optimization)
3. Automate model selection via cross-validated performance
4. Construct ensemble methods (stacking, voting, boosting)
5. Build a complete end-to-end automated ML pipeline
6. Handle data leakage and pipeline validation
