# Feature Engineering Automation

## Overview
Automated generation and selection of features for machine learning. Covers polynomial features, interaction terms, binning, encoding, and feature selection algorithms.

## Learning Objectives
1. Generate polynomial and interaction features automatically
2. Implement binning strategies (equal-width, equal-frequency, adaptive)
3. Build categorical encoding (one-hot, target, frequency, WOE)
4. Apply feature selection (filter, wrapper, embedded methods)
5. Build a feature engineering pipeline
6. Automatic feature transformation search
