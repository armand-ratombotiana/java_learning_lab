# Time Series Analysis

## Overview
Methods for analyzing and forecasting time-ordered data. Covers decomposition (trend/seasonal/residual), ARIMA modeling, exponential smoothing, and model evaluation.

## Learning Objectives
1. Decompose time series into trend, seasonal, and residual components
2. Implement ARIMA (Autoregressive Integrated Moving Average) models
3. Apply exponential smoothing (Holt-Winters) methods
4. Evaluate forecast accuracy (MAE, RMSE, MASE, forecast bias)
5. Handle stationarity via differencing and transformations
6. Model selection via AIC, BIC, and cross-validation
