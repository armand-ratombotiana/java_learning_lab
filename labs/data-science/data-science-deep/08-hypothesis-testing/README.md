# Hypothesis Testing Framework

## Overview
Comprehensive hypothesis testing framework implementing parametric and non-parametric tests. Covers t-test, chi-square, ANOVA, Mann-Whitney U, Kruskal-Wallis, and bootstrap-based tests.

## Learning Objectives
1. Implement one-sample, two-sample, and paired t-tests
2. Apply chi-square tests for independence and goodness-of-fit
3. Perform one-way and two-way ANOVA
4. Implement non-parametric tests (Mann-Whitney, Wilcoxon, Kruskal-Wallis)
5. Use bootstrap for permutation-based hypothesis testing
6. Handle multiple testing corrections and power analysis
