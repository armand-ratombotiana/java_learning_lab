# Company Interview Guide for Data Science Roles

## Google
- **Focus Areas**: Experimental design, causal inference, A/B testing at scale, statistical methodology
- **Typical Rounds**: 2x statistics & experimentation, 1x ML system design, 1x coding, 1x behavioral
- **Key Topics**: Counterfactual reasoning, metric design, switchback experiments, variance reduction
- **Preparation**: Review Google's papers on experimentation, Overlapping Experiment Infrastructure

## Meta (Facebook)
- **Focus Areas**: Hypothesis testing, experimentation platforms, causal inference, product metrics
- **Typical Rounds**: 2x statistics & probability, 1x ML design, 1x behavioral, 1x coding (optional)
- **Key Topics**: Sequential testing, multiple testing correction, delta method for ratio metrics
- **Preparation**: Study Meta's Experimentation Platform papers, variance reduction techniques

## Amazon
- **Focus Areas**: Causal inference, time-series forecasting, A/B testing, business metrics
- **Typical Rounds**: 2x statistics & ML, 1x bar raiser (behavioral), 1x coding, 1x ML system design
- **Key Topics**: Diff-in-diff, instrumental variables, offline evaluation of online metrics
- **Preparation**: Focus on LP (Leadership Principles) stories, Amazon's scientist blog posts

## Netflix
- **Focus Areas**: Experimental design, causal inference, personalization, recommendation metrics
- **Typical Rounds**: 1x statistics, 1x ML system design, 1x coding, 1x behavioral, 1x presentation
- **Key Topics**: Switchback experiments, interleaving experiments, counterfactual evaluation
- **Preparation**: Read Netflix Tech Blog experimentation posts, causal inference in recommendations

## Apple
- **Focus Areas**: Experimental design, hypothesis testing, ML pipeline, privacy-preserving stats
- **Typical Rounds**: 2x statistics & ML, 2x coding, 1x behavioral
- **Key Topics**: Frequentist vs Bayesian, differential privacy, on-device experimentation
- **Preparation**: Review Apple privacy papers, differential privacy in statistical testing

## Uber
- **Focus Areas**: Causal inference, time series forecasting, experimentation at scale, marketplace dynamics
- **Typical Rounds**: 1x statistics, 1x ML system design, 2x coding, 1x behavioral
- **Key Topics**: Market-level experimentation, network effects, spillover, switchback experiments
- **Preparation**: Study Uber's engineering blog on experimentation, causal inference in two-sided markets

## Microsoft
- **Focus Areas**: A/B testing, observational causal inference, ML interpretability, responsible AI
- **Typical Rounds**: 2x statistics & ML, 1x system design, 1x coding, 1x behavioral
- **Key Topics**: Online controlled experiments, quasi-experimental designs, fairness metrics
- **Preparation**: Read Microsoft's experimentation whitepapers, Responsible AI resources

## Common Question Types by Round

### Statistics Round
- Design an A/B test for X feature
- Calculate sample size given parameters
- Explain p-values, confidence intervals, power
- Deal with multiple testing corrections
- Handle metric selection and guardrail metrics

### ML Design Round
- Design a recommendation system
- Design a fraud detection pipeline
- Design a forecasting system
- Design a personalization algorithm

### Coding Round
- Implement t-test from scratch
- Implement bootstrap sampling
- Implement k-fold cross-validation
- Implement feature scaling and normalization
- LeetCode medium: arrays, strings, hash maps, trees
