# Bayesian Statistics

## Overview
Bayesian inference framework using prior distributions, likelihoods, and posterior computation. Covers conjugate models, MCMC sampling (Metropolis-Hastings, Gibbs), credible intervals, and model comparison.

## Learning Objectives
1. Apply Bayes' theorem for posterior inference
2. Implement conjugate prior models (Beta-Binomial, Normal-Normal, Gamma-Poisson)
3. Perform MCMC sampling (Metropolis-Hastings, Gibbs sampling)
4. Compute credible intervals and highest posterior density (HPD) regions
5. Compare models using Bayes factors and WAIC
6. Build hierarchical Bayesian models
