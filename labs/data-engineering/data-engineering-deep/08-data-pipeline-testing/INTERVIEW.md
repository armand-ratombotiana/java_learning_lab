# Lab 08: Data Pipeline Testing — Interview Questions

1. **What is a data contract** and how does it differ from a schema?

2. **Design a testing strategy for a pipeline with 50+ upstream sources**.

3. **How do you test a Kafka Streams application**? What's the testing pyramid look like?

4. **What is consumer-driven contract testing** for data pipelines?

5. **How do you handle flaky tests in data pipeline CI/CD**?

6. **Design a system to validate data contracts** before deploying pipeline changes.

7. **How do you test schema evolution** in a production database without breaking consumers?

8. **What's the difference between forward and backward compatibility** for Avro schemas?

9. **How would you test that a pipeline handles late-arriving data correctly**?

10. **Design a data quality test suite** that runs as part of a CI pipeline.

11. **How do you mock external dependencies** (S3, Kafka, JDBC) in pipeline tests?

12. **What metrics would you track for pipeline test coverage**?

13. **How do you test idempotency** of a data pipeline?

14. **Design a canary deployment strategy** for a critical data pipeline.

15. **How would you test a pipeline that processes 1TB of data** without running it in production?
