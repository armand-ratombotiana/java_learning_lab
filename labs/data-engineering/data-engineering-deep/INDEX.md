# Data Engineering Deep-Dive Micro-Labs

## Overview

Ten intensive, hands-on micro-labs covering the most critical advanced topics in modern data engineering. Each lab includes a conceptual guide, Java implementation, FAANG interview prep, and a full mock interview transcript.

## How to Use

1. **Pick a lab** from the index above based on your interview target or skill gap.
2. **Start with README.md** for the high-level overview and learning objectives.
3. **Work through GUIDE.md** for a step-by-step tutorial with runnable Java examples.
4. **Attempt PROBLEM_WALKTHROUGH.md** to implement the lab's capstone exercise.
5. **Test yourself with INTERVIEW.md** — 15+ FAANG-style questions per lab.
6. **Review MOCK_INTERVIEW.md** to see how a senior engineer would respond under interview conditions.
