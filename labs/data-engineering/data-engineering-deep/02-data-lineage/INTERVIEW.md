# Lab 02: Data Lineage — Interview Questions

1. **Design a column-level lineage system** for a data warehouse with 10,000 tables.

2. **How would you capture lineage from Spark SQL queries** without modifying the Spark source?

3. **Compare OpenLineage vs custom lineage**. When is each appropriate?

4. **How do you handle lineage for transformations in Kafka Streams**?

5. **Design a system to detect broken lineage** (orphan datasets, dangling references).

6. **How do you represent lineage for schema evolution** — e.g., a column was renamed?

7. **What storage format would you use for lineage metadata**? Graph DB vs relational?

8. **How would you perform impact analysis across 5000+ pipelines** efficiently?

9. **Design a lineage visualization** that doesn't overwhelm users with complex DAGs.

10. **How do you capture lineage from a SQL query that uses CTEs and subqueries**?

11. **What's the difference between dataset-level and column-level lineage**? When do you need each?

12. **How would you integrate lineage into a data quality framework**?

13. **Design a system to backfill lineage** for historical pipelines that never captured it.

14. **How do you handle lineage for UDFs** (user-defined functions)?

15. **What are the performance implications of capturing lineage at runtime** in a high-throughput pipeline?
