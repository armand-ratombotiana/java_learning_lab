# Lab 03: Data Catalog — Interview Questions

1. **Design a data catalog for a company with 100,000 datasets**. How do you handle scale?

2. **Compare Amundsen, DataHub, and OpenMetadata**. What are the trade-offs?

3. **How do you implement schema evolution compatibility** (BACKWARD, FORWARD, FULL)?

4. **Design a search system** for a data catalog that handles typos and synonyms.

5. **How would you automatically populate a data catalog** from existing data lake metadata?

6. **What metadata would you track for a Kafka topic** vs a Hive table vs a dashboard?

7. **How do you handle dataset ownership and stewardship** in a catalog?

8. **Design a tagging system** that supports hierarchical tags and tag inheritance.

9. **How do you integrate a data catalog with a data quality framework**?

10. **What's the difference between a data catalog and a data dictionary**?

11. **How would you implement column-level popularity** (most queried columns) in a catalog?

12. **Design a system to detect and resolve dataset duplicates** in a catalog.

13. **How do you handle PII/classification labels** in dataset metadata?

14. **What APIs would you expose** for a data catalog REST service?

15. **How would you version the data catalog's own metadata schema**?
