# Lab 03: Data Catalog

## Overview

Implement a data catalog service for metadata management, dataset discovery, and schema registry with search and tagging capabilities.

## Learning Objectives

- Design a metadata storage model for datasets, schemas, and tags
- Build a search and discovery API with faceted filtering
- Implement schema versioning and compatibility checks
- Create a tagging and annotation system

## Key Concepts

- **Metadata Management**: Centralized repository of data asset metadata
- **Schema Registry**: Versioned schema storage with compatibility
- **Data Discovery**: Search, browse, and filter datasets
- **Business Glossary**: Domain-specific naming and definitions
- **OpenMetadata / Amundsen**: Reference catalog implementations
