# Lab 09: Real-Time Analytics — Interview Questions

1. **Design a real-time dashboard** that displays revenue metrics with sub-second latency.

2. **Compare tumbling, hopping, and sliding windows**. When would you use each?

3. **How does Flink handle watermarking and late data** differently from Kafka Streams?

4. **Design a real-time anomaly detection system** for 100K events/sec.

5. **How do you handle out-of-order events** in a streaming revenue aggregation?

6. **Design a system to backfill a real-time dashboard** when there's a data gap.

7. **How would you implement exactly-once counting** in a real-time analytics pipeline?

8. **What's the trade-off between latency and accuracy** in real-time aggregations?

9. **How do you choose the window size** for a real-time dashboard? What factors matter?

10. **Design a materialized view that joins a stream with a slowly changing dimension**.

11. **How do you test a real-time dashboard** without running it against production data?

12. **What storage backend would you use** for serving real-time dashboard queries?

13. **How do you scale a real-time analytics pipeline** from 1K to 1M events/sec?

14. **Design an alerting system for metric anomalies** in a real-time dashboard.

15. **How would you implement A/B testing metrics** in a real-time pipeline?
