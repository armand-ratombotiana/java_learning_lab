# Lab 07: Data Mesh Architecture

## Overview

Implement core data mesh concepts — domain ownership, data products, cross-domain data sharing, and federated governance.

## Learning Objectives

- Understand the four principles of data mesh
- Model data products with inputs, outputs, and SLAs
- Implement a domain catalog for inter-domain discovery
- Design a federated governance policy across domains

## Key Concepts

- **Domain Ownership**: Each domain owns its data end-to-end
- **Data as a Product**: Apply product thinking to datasets
- **Self-Serve Infrastructure**: Shared platform for domains
- **Federated Governance**: Global standards + local autonomy
- **Data Product**: Input port, output port, compute, metadata
