# Lab 07: Data Mesh Architecture — Interview Questions

1. **Explain the four principles of data mesh** and how they address the limitations of the centralized data lake.

2. **How do you define a "data product"** in practice? What are the essential components?

3. **Design a cross-domain data sharing mechanism** when domains use different storage systems.

4. **How does federated governance differ from centralized governance**?

5. **What's the role of a "data platform" team** in a data mesh architecture?

6. **How do you handle data quality across domains** when each domain owns their data?

7. **Design a system for domain discovery** — how does domain A find domain B's data products?

8. **How do you implement global schema standards** while allowing local schema flexibility?

9. **What's the difference between data mesh and data fabric**?

10. **How do you handle PII across domains** in a mesh architecture?

11. **Design a cost allocation model** for data mesh (who pays for storage/compute).

12. **How would you migrate a monolithic data lake to a data mesh**?

13. **What SLAs would you define for a data product**?

14. **How do you handle data contracts** between producer and consumer domains?

15. **Design a system to detect and prevent "data silos"** in a mesh architecture.
