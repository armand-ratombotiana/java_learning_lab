# Lab 06: Data Governance — Interview Questions

1. **Design a data governance system** for a multi-tenant data platform with 500 teams.

2. **Compare RBAC vs ABAC** for data access control. When would you use each?

3. **How do you handle data residency requirements** (GDPR, CCPA) in a global data platform?

4. **Design a system to automatically detect and classify PII** in a data lake.

5. **How do you implement column-level access control** in a data warehouse?

6. **What is "purpose limitation"** and how do you enforce it in data governance?

7. **Design an audit system** that can handle 10M access events per day.

8. **How do you handle data deletion (right to be forgotten)** across all systems?

9. **What are data retention policies** and how do you implement them?

10. **How do you govern access to derived datasets** (aggregations, ML features)?

11. **Design a system to enforce data quality SLAs** as a governance policy.

12. **How do you handle cross-team data sharing** with governance controls?

13. **What metadata is essential for data governance**?

14. **How do you implement "data contracts"** between producers and consumers?

15. **Design a compliance reporting system** for data access reviews.
