# Lab 06: Data Governance Framework

## Overview

Implement a data governance framework with role-based access control, policy enforcement, audit logging, and data classification.

## Learning Objectives

- Design a policy engine for data access rules
- Implement RBAC (role-based access control) for datasets
- Build an audit logging system for data access
- Create a data classification and tagging hierarchy

## Key Concepts

- **RBAC**: Roles, permissions, resource hierarchy
- **ABAC**: Attribute-based access control (complementary)
- **Policy Engine**: Rule evaluation with allow/deny/audit
- **Audit Trail**: Immutable log of all data access events
- **Classification**: PII, sensitive, public, internal tiers
