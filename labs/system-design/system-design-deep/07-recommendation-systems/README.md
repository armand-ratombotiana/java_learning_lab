# Lab 07: Recommendation Systems

## Overview
Master recommendation system algorithms: collaborative filtering, content-based filtering, hybrid approaches, matrix factorization, and real-time recommendation design.

## Approaches

| Approach | Input | Technique | Use Case |
|----------|-------|-----------|----------|
| **Collaborative Filtering** | User-item interactions | User-based / Item-based KNN | Amazon "Customers who bought" |
| **Content-Based** | Item features | TF-IDF, cosine similarity | News/article recommendations |
| **Hybrid** | Interactions + features | Weighted combination | Netflix, Spotify |
| **Matrix Factorization** | User-item matrix | SVD, ALS, NMF | Latent factor discovery |
| **Real-Time** | Streaming events | Online learning, bandits | Session-based recommendations |

## Learning Objectives
- Implement user-based and item-based collaborative filtering
- Build content-based recommendation with TF-IDF cosine similarity
- Design a hybrid recommendation engine
- Implement matrix factorization (SVD)
- Build a real-time recommendation system with online updates
