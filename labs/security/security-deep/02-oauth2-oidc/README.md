# OAuth2 & OIDC

## Overview
This micro-lab covers **OAuth2 & OIDC**, including OAuth2 flows, JWT, OpenID Connect, token validation, and refresh tokens. Essential for modern API security, single sign-on, and distributed authorization.

## Topics Covered
- OAuth2 roles: resource owner, client, authorization server, resource server
- Authorization code flow (with PKCE), implicit flow, client credentials flow
- JWT structure: header, payload, signature, claims
- OpenID Connect: ID token, UserInfo endpoint, discovery
- Token validation, refresh tokens, token revocation

## Learning Objectives
1. Implement the OAuth2 authorization code flow
2. Create and validate JWT tokens with RS256/HS256
3. Simulate OpenID Connect authentication
4. Implement refresh token rotation
5. Validate tokens using JWKS endpoints
