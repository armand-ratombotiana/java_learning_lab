# API Security

## Overview
This micro-lab covers **API Security**, including API authentication, rate limiting, input validation, and the OWASP API Top 10. Essential for microservices security, web API development, and backend engineering.

## Topics Covered
- API authentication: API keys, JWT, OAuth2 client credentials, mutual TLS
- Rate limiting: token bucket, leaky bucket, sliding window, per-user limits
- Input validation: schema validation, allowlist vs blocklist, sanitization
- OWASP API Top 10: broken auth, excessive data exposure, mass assignment
- API security testing and monitoring

## Learning Objectives
1. Implement API key authentication with hashing and rotation
2. Design token bucket and sliding window rate limiters
3. Validate API inputs against JSON Schema
4. Identify and mitigate OWASP API Top 10 vulnerabilities
5. Implement secure API gateway patterns
