# Container Security

## Overview
This micro-lab covers **Container Security**, including Docker security, image scanning, runtime security, and Kubernetes security. Essential for cloud-native security, DevSecOps, and platform engineering.

## Topics Covered
- Docker security: host configuration, container isolation, seccomp, AppArmor
- Image scanning: vulnerability scanning, base image selection, distroless images
- Runtime security: Falco, Sysdig, audit logging
- Kubernetes security: RBAC, Pod Security Standards, network policies, secrets management
- Supply chain security: image signing (Cosign), SBOM

## Learning Objectives
1. Implement Dockerfile security best practices
2. Scan container images for known vulnerabilities
3. Configure Kubernetes RBAC with least privilege
4. Apply Pod Security Standards and OPA Gatekeeper policies
5. Implement image signing and verification with Cosign
