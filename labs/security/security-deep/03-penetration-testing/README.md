# Penetration Testing

## Overview
This micro-lab covers **Penetration Testing**, including scanning, enumeration, exploitation, reporting, and vulnerability classification. Essential for offensive security, red teaming, and security assessment.

## Topics Covered
- Reconnaissance: passive and active information gathering
- Scanning: port scanning, service detection, OS fingerprinting
- Enumeration: extracting user accounts, shares, services
- Exploitation: vulnerability identification and exploitation
- Reporting: findings documentation, remediation recommendations, CVSS scoring

## Learning Objectives
1. Perform network scanning and service discovery
2. Enumerate system users, services, and misconfigurations
3. Classify vulnerabilities using CVE and CVSS frameworks
4. Understand common exploitation techniques
5. Write professional penetration testing reports
