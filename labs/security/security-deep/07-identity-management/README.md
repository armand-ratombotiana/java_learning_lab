# Identity Management

## Overview
This micro-lab covers **Identity Management**, including SSO, LDAP, SAML, SCIM, identity federation, and MFA. Essential for enterprise security, identity governance, and zero trust architectures.

## Topics Covered
- Single Sign-On (SSO): benefits, protocols, SP-initiated vs IdP-initiated
- LDAP: directory structure, binds, searches, authentication
- SAML 2.0: assertions, protocols, bindings, metadata exchange
- SCIM: user provisioning, group management, schema, REST API
- Identity federation: social login, cross-domain SSO, trust relationships
- Multi-Factor Authentication (MFA): TOTP, HOTP, FIDO2/WebAuthn

## Learning Objectives
1. Implement LDAP authentication and search operations
2. Create and validate SAML assertions
3. Implement SCIM user provisioning endpoints
4. Generate and validate TOTP codes for MFA
5. Design federated identity architecture
