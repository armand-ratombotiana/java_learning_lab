# SAST & DAST

## Overview
This micro-lab covers **SAST & DAST**, including static/dynamic analysis, SAST tools, DAST tools, and code review automation. Essential for DevSecOps, secure SDLC, and application security testing.

## Topics Covered
- Static Application Security Testing (SAST): source code analysis, taint tracking
- Dynamic Application Security Testing (DAST): runtime testing, fuzzing
- SAST tools: SonarQube, Checkmarx, Semgrep, CodeQL
- DAST tools: OWASP ZAP, Burp Suite, Netsparker, Acunetix
- CI/CD integration and automated code review pipelines

## Learning Objectives
1. Implement a simple SAST scanner for common vulnerability patterns
2. Design a DAST crawler for web application testing
3. Understand false positive vs false negative tradeoffs
4. Integrate security scanning into CI/CD pipelines
5. Perform automated code review using pattern matching
