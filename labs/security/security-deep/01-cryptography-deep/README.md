# Cryptography Deep

## Overview
This micro-lab provides a deep-dive exploration of **Cryptography Deep**, covering AES, RSA, Diffie-Hellman, ECC, and digital signatures. Essential for secure communications, data protection, blockchain, and modern authentication systems.

## Topics Covered
- Symmetric encryption: AES (ECB, CBC, GCM modes)
- Asymmetric encryption: RSA key generation, encryption, decryption
- Key exchange: Diffie-Hellman protocol
- Elliptic Curve Cryptography (ECC) basics
- Digital signatures: RSA signatures, ECDSA, DSA

## Learning Objectives
1. Implement AES encryption/decryption in various modes
2. Generate RSA key pairs and perform encryption/decryption
3. Simulate Diffie-Hellman key exchange
4. Understand ECC fundamentals and ECDSA signatures
5. Implement RSA-based digital signature scheme
