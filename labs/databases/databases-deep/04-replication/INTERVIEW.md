# Replication — Interview Questions

## Beginner
1. What is the difference between synchronous and asynchronous replication?
2. What is replication lag and how do you measure it?
3. What is a read replica used for?

## Intermediate
4. Explain logical replication and how it differs from physical replication.
5. What are the failure scenarios in async replication? How does semi-sync help?
6. How does PostgreSQL's `synchronous_standby_names` configuration work?

## Advanced
7. Design a conflict resolution strategy for a multi-master system with offline partitions.
8. How would you implement cross-region replication with RPO < 1 second?
9. Explain the interplay between replication and snapshot isolation.

## System Design
10. Design a global database replication architecture for an e-commerce platform with active-active regions.
