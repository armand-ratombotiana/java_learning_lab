# 08 - Database Security

## Topics Covered
- Encryption at rest (TDE, file-level, column-level)
- Encryption in transit (TLS, mTLS)
- Row-Level Security (RLS, policies)
- Audit logging (triggers, built-in audit)
- Connection security (IAM, certificates, passwords)
- SQL injection prevention (parameterized queries, prepared statements)
- Authentication and Authorization (RBAC, ABAC)

## Goal
Understand the layered security model for protecting data in databases.

## Exercises

1. Row-Level Security: Create a policy that restricts users to their own rows.
2. Audit logging: Implement a trigger-based audit trail.
3. Simulate a SQL injection attack and demonstrate parameterized query prevention.
4. Implement column-level encryption using AES-GCM.
