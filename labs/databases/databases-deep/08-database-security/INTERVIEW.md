# Database Security — Interview Questions

## Beginner
1. What is encryption at rest vs encryption in transit?
2. What is SQL injection and how do you prevent it?
3. What is the principle of least privilege in database access?

## Intermediate
4. Explain how Row-Level Security works in PostgreSQL.
5. What is the difference between authentication and authorization?
6. How does mTLS improve database connection security beyond TLS?

## Advanced
7. Design an audit logging strategy for a HIPAA-compliant database.
8. How would you rotate encryption keys for column-level encryption without downtime?
9. What are the security implications of dynamic SQL in stored procedures?

## System Design
10. Design a multi-tenant database security architecture where tenants are isolated at the row level but share a schema.
