# Lab 02: Logistic Regression

## Topics Covered
- Binary Classification
- Sigmoid Function
- Cross-Entropy Loss
- Decision Boundary

## Objective
Implement logistic regression from scratch using gradient descent and binary cross-entropy loss.

## Key Concepts
| Concept | Description |
|---|---|
| Sigmoid | σ(z) = 1 / (1 + e⁻ᶻ), maps any real to [0, 1] |
| Decision Boundary | σ(βᵀx) ≥ 0.5 → class 1 |
| Cross-Entropy | J(β) = −(1/m) Σ [y log(ŷ) + (1−y) log(1−ŷ)] |
