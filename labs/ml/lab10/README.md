# Lab 10: Model Evaluation

## Topics Covered
- Cross-Validation
- Confusion Matrix
- ROC / AUC
- Precision-Recall Curve
- Bias-Variance Tradeoff

## Objective
Implement evaluation metrics and k-fold cross-validation from scratch.

## Key Concepts
| Concept | Description |
|---|---|
| K-Fold CV | Split data into K folds; train on K−1, validate on 1 |
| Confusion Matrix | TP, FP, FN, TN |
| ROC Curve | TPR vs FPR across thresholds |
| AUC | Area under ROC curve |
| Precision-Recall | Useful for imbalanced datasets |
| Bias-Variance | Underfitting (high bias) vs overfitting (high variance) |
