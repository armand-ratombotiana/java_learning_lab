# LeetCode Pattern Cheatsheet

## Array / String
- **Two Pointers**: Sorted arrays, palindrome check, remove duplicates.
- **Sliding Window**: Subarray/substring problems, max/min in window.
- **Prefix Sum**: Range sum queries, subarray sum equals K.

## Linked List
- **Fast & Slow Pointer**: Cycle detection, middle of list.
- **Reverse**: In-place reversal, reverse K groups.
- **Merge**: Merge two sorted lists, merge sort.

## Tree / Graph
- **DFS (Recursive)**: Path sum, tree max depth, binary tree traversal.
- **BFS (Queue)**: Level-order traversal, shortest path in grid.
- **Union-Find**: Connected components, number of islands.
- **Topological Sort**: Course schedule, dependency resolution.

## Dynamic Programming
- **0/1 Knapsack**: Subset sum, partition equal sum.
- **Unbounded Knapsack**: Coin change, rod cutting.
- **LIS/LCS**: Longest increasing subsequence, longest common subsequence.
- **Palindromes**: Longest palindromic substring, count palindromes.
- **Grid DP**: Unique paths, min path sum, dungeon game.

## Binary Search
- **Classic**: Sorted array search, first/last occurrence.
- **Rotated Array**: Search in rotated sorted, find min in rotated.
- **Unbounded Search**: Find peak, find in infinite array.

## Heap / Priority Queue
- **Top K Elements**: Kth largest, top K frequent.
- **Merge K Sorted**: Lists, arrays, files.
- **Median**: Find median from data stream.

## Backtracking
- **Permutations / Combinations**: Generate all subsets, permutations.
- **Constraint Satisfaction**: N-Queens, Sudoku solver.
- **Pruning**: Branch and bound, memoization.

## Bit Manipulation
- **XOR Tricks**: Single number, missing number, find duplicates.
- **Bitmask DP**: TSP, subset DP.
- **Power of Two**: n & (n−1), n & (−n).

## Time Complexities to Memorize
- O(1) — Constant: hash lookup
- O(log n) — Logarithmic: binary search
- O(n) — Linear: array traversal
- O(n log n) — Sorting: merge sort, heap sort
- O(n²) — Quadratic: nested loops
- O(2ⁿ) — Exponential: subsets, recursion without memo
- O(n!) — Factorial: permutations
