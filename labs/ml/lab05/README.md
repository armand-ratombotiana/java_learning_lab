# Lab 05: K-Nearest Neighbors

## Topics Covered
- Distance Metrics (Euclidean, Manhattan, Minkowski)
- K Selection
- Weighted Voting
- Curse of Dimensionality

## Objective
Implement KNN classifier from scratch and analyze the effect of K and distance metrics.

## Key Concepts
| Concept | Description |
|---|---|
| Euclidean Distance | √Σ(xᵢ − yᵢ)² |
| Manhattan Distance | Σ|xᵢ − yᵢ| |
| Weighted Voting | Weight = 1 / distance |
| Curse of Dimensionality | Points become equidistant as dimensions increase |
