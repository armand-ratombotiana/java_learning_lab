# ML Academy — Index

## Overview
The ML Academy provides a structured, hands-on curriculum covering essential machine learning algorithms and techniques. Each lab includes theoretical background, implementation guide, interview Q&A, and compilable Java source code.

## Labs

| # | Lab | Topics |
|---|-----|--------|
| 01 | Linear Regression | OLS, Gradient Descent, R², MSE/MAE, Assumptions |
| 02 | Logistic Regression | Binary Classification, Sigmoid, Cross-Entropy, Decision Boundary |
| 03 | Decision Trees & Random Forests | ID3, CART, Gini, Entropy, Bagging, Feature Importance |
| 04 | Support Vector Machines | Maximum Margin, Kernel Trick, Soft Margin, SMO |
| 05 | K-Nearest Neighbors | Distance Metrics, K Selection, Weighted Voting, Curse of Dimensionality |

| 10 | Model Evaluation | Cross-Validation, Confusion Matrix, ROC/AUC, Precision-Recall, Bias-Variance |
