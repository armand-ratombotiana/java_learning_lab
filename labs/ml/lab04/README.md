# Lab 04: Support Vector Machines

## Topics Covered
- Maximum Margin Classifier
- Kernel Trick
- Soft Margin
- SMO (Sequential Minimal Optimization)

## Objective
Understand the SVM objective (maximizing margin), implement a linear SVM, and explore the kernel trick.

## Key Concepts
| Concept | Description |
|---|---|
| Maximum Margin | Find hyperplane that maximizes distance to nearest points |
| Support Vectors | Data points that define the margin |
| Kernel Trick | Map data to higher dimension without explicit computation |
| Soft Margin | Allow misclassifications via slack variables ξᵢ |
| SMO | Efficient optimization for SVM dual problem |
