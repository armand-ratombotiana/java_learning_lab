# Lab 08: Principal Component Analysis

## Topics Covered
- Eigenvalue Decomposition
- Variance Explained
- Dimensionality Reduction

## Objective
Implement PCA from scratch using eigenvalue decomposition of the covariance matrix.

## Key Concepts
| Concept | Description |
|---|---|
| Covariance Matrix | Σ = (1/n) XᵀX (after centering) |
| Eigenvalue Decomposition | Σ·v = λ·v |
| Explained Variance | λᵢ / Σ λⱼ |
| Principal Components | Eigenvectors sorted by descending eigenvalue |
