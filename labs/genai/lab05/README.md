# Lab 05: LLM Agent Frameworks

## Overview
Build an LLM agent framework with ReAct (Reasoning + Acting) loop, tool registration, multi-step reasoning, and observability.

## Learning Objectives
- Implement the ReAct agent loop
- Design a tool registry with typed functions
- Build multi-step reasoning with observation tracking
- Add agent observability (thought traces)

## Prerequisites
- Java 21+
- Labs 01–04
- Understanding of LLM function calling
