# Lab 11: Model Quantization & Deployment

## Overview
Learn model quantization techniques (INT8, FP16) and deployment concepts including ONNX export, TensorRT optimization, and GPU inference.

## Learning Objectives
- Implement INT8 quantization (symmetric/asymmetric)
- Implement FP16 half-precision conversion
- Understand ONNX graph representation
- Simulate TensorRT optimization

## Prerequisites
- Java 21+
- Labs 01–02
- Basic understanding of floating-point formats
