# Lab 15: Building a GenAI Platform

## Overview
Design and implement an end-to-end GenAI platform architecture covering model serving, API gateway, orchestration, observability, and multi-model support.

## Learning Objectives
- Design a multi-model serving architecture
- Implement an API gateway with routing
- Build a model orchestrator with fallback
- Implement A/B testing framework
- Design a complete system architecture

## Prerequisites
- Java 21+
- All previous labs
- Understanding of microservices
