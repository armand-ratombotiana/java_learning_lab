# Lab 15: Building a GenAI Platform Guide

## Step 1: API Gateway
Route requests to appropriate model endpoints.

## Step 2: Model Registry
Register, version, and discover models.

## Step 3: Orchestrator
Chain multiple model calls, handle fallbacks.

## Step 4: A/B Testing
Route traffic between model versions, collect metrics.

## Step 5: Rate Limiting
Implement token-based and request-based rate limiting.

## Step 6: Platform Dashboard
Aggregate metrics across all components.

## Compile & Run
```bash
cd lab15/src
javac com/genai/lab15/Main.java
java com.genai.lab15.Main
```
