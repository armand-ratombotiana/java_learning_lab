# Lab 13: Context Window Management

## Overview
Explore techniques to manage and extend the context window of LLMs including sliding window attention, Rotary Position Embedding (RoPE), context compression, and memory-efficient attention.

## Learning Objectives
- Implement sliding window attention
- Understand Rotary Position Embedding (RoPE)
- Build a context compression module
- Implement ALiBi position encoding

## Prerequisites
- Java 21+
- Lab 01, 02
- Linear algebra fundamentals
