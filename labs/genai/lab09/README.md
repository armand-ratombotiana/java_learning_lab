# Lab 09: LLM Evaluation & Benchmarks

## Overview
Learn to evaluate LLMs across multiple dimensions: accuracy, toxicity, bias, factual consistency, and hallucination detection.

## Learning Objectives
- Implement accuracy metrics (BLEU, ROUGE, F1)
- Build a toxicity classifier
- Measure bias using demographic parity
- Implement factual consistency scoring

## Prerequisites
- Java 21+
- Basic NLP concepts
- Understanding of precision/recall
