# Lab 12: Cost Optimization for LLMs

## Overview
Learn techniques to reduce LLM inference and training costs including caching, dynamic batching, prompt compression, and speculative decoding.

## Learning Objectives
- Implement semantic caching with embeddings
- Build a dynamic batching scheduler
- Implement prompt compression (stop-word removal, summarization)
- Understand speculative decoding concept

## Prerequisites
- Java 21+
- Labs 01, 04
