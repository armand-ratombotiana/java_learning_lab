# Lab 08: Multimodal Models

## Overview
Explore multimodal AI models that combine text and image understanding. Understand CLIP architecture, cross-modal attention, and multimodal fusion.

## Learning Objectives
- Implement a simplified CLIP-style dual encoder
- Build cross-modal attention mechanism
- Understand image patch embedding
- Implement contrastive loss for alignment

## Prerequisites
- Java 21+
- Labs 01–02
- Basic understanding of CNNs
