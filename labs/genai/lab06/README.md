# Lab 06: Fine-Tuning with LoRA/QLoRA

## Overview
Understand parameter-efficient fine-tuning using Low-Rank Adaptation (LoRA). Implement the core linear algebra concepts and simulate LoRA training in Java.

## Learning Objectives
- Understand LoRA rank decomposition
- Implement LoRA weight injection
- Simulate LoRA forward pass
- Understand QLoRA quantization concepts

## Prerequisites
- Java 21+
- Labs 01–02
- Basic linear algebra
