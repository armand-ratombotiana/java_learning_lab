# Lab 02: GPT Architecture

## Overview
Explore the decoder-only GPT architecture including causal language modeling, autoregressive generation, tokenization, and the KV cache mechanism.

## Learning Objectives
- Implement causal (masked) self-attention
- Build an autoregressive token generator
- Understand Byte-Pair Encoding (BPE) tokenization
- Implement a KV cache for efficient inference

## Prerequisites
- Java 21+
- Lab 01: Transformer concepts
- Basic understanding of language modeling
