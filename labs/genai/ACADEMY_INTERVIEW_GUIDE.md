# GenAI Academy Interview Guide

## How to Prepare
1. **Master fundamentals**: Transformer, attention, embeddings, tokenization.
2. **Hands-on code**: All 15 labs contain compilable Java that demonstrates core concepts.
3. **System design**: Know RAG pipelines, agent loops, caching strategies, deployment topologies.
4. **Behavioral**: Use STAR format — Situation, Task, Action, Result.

## FAANG Interview Structure
1. **Phone Screen** — 1–2 coding problems + high-level ML discussion.
2. **On-site** — 4–6 rounds: coding, ML depth, system design, behavioral.
3. **ML-specific rounds** — Derive backprop, attention from scratch, discuss trade-offs.
