# Lab 03: Prompt Engineering Guide

## Step 1: Prompt Template Engine
Build a `PromptTemplate` class that substitutes variables.

## Step 2: Few-Shot Learning
Create templates that include example input-output pairs.

## Step 3: Chain-of-Thought (CoT)
Add "Let's think step by step" reasoning traces.

## Step 4: Structured Output Parsing
Parse JSON, XML, or custom formats from LLM responses.

## Step 5: Prompt Versioning
Manage prompt versions with hash-based deduplication.

## Compile & Run
```bash
cd lab03/src
javac com/genai/lab03/Main.java
java com.genai.lab03.Main
```
