# Lab 03: Prompt Engineering Patterns

## Overview
Master prompt engineering techniques including few-shot learning, chain-of-thought reasoning, structured prompting, and programmatic prompt construction.

## Learning Objectives
- Implement few-shot prompt templating
- Build a chain-of-thought reasoning pipeline
- Create structured output parsers
- Understand prompt versioning

## Prerequisites
- Java 21+
- Basic understanding of LLM APIs
