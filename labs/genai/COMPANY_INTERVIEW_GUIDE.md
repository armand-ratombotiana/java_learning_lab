# Company Interview Guide for GenAI Roles

## Google
- ML depth focus: transformer math, scaling laws, loss functions.
- Coding: DP, graphs, arrays — strong general CS.
- System design: large-scale retrieval, serving, recommendation.

## Meta (FAIR/GenAI)
- Emphasis on PyTorch internals, distributed training (FSDP).
- Coding: dynamic programming, strings, medium-hard LeetCode.
- Behavioral: Move fast, shipping mentality.

## OpenAI
- Deep understanding of GPT architecture, RLHF, safety.
- Coding: implement attention, tokenization, sampling.
- Research-oriented: discuss papers, trade-offs.

## Anthropic
- Safety alignment, constitutional AI, interpretability.
- System design: trustworthy deployment, monitoring.
- Coding: algorithmic reasoning, medium difficulty.

## Microsoft (Azure AI/Copilot)
- Full-stack GenAI: orchestration, prompt flow, RAG.
- Cloud architecture: Azure ML, Kubernetes, GPU infra.
- Coding: broad (LC medium).

## Amazon (AGI / Alexa)
- Customer-obsessed GenAI applications.
- Bar raiser behavioral round.
- System design: large-scale inference, cost optimization.
