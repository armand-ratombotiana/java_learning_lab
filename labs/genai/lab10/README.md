# Lab 10: LLM Safety & Alignment

## Overview
Implement safety mechanisms for LLMs including guardrails, content filtering, prompt injection detection, and red-teaming strategies.

## Learning Objectives
- Build input/output guardrails
- Implement content filtering (deny list, regex)
- Detect prompt injection attempts
- Simulate red-teaming attacks

## Prerequisites
- Java 21+
- Labs 03, 09
