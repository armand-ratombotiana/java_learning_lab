# Lab 07: RLHF & Preference Optimization

## Overview
Understand Reinforcement Learning from Human Feedback (RLHF) — reward modeling, Proximal Policy Optimization (PPO) basics, and Direct Preference Optimization (DPO).

## Learning Objectives
- Implement a reward model training loop
- Simulate PPO policy update
- Understand preference data formatting
- Compare RLHF vs DPO approaches

## Prerequisites
- Java 21+
- Labs 01–02
- Basic reinforcement learning concepts
