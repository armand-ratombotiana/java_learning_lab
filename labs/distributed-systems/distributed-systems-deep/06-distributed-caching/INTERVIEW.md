# Distributed Caching — Interview Questions

## Beginner
1. What is cache-aside and when would you use it?
2. What is the difference between write-through and write-behind?
3. What is cache invalidation and why is it hard?

## Intermediate
4. Explain write-invalidate vs write-update coherence protocols.
5. How does Redis Cluster distribute keys across nodes?
6. What is a cache stampede and how do you prevent it?

## Advanced
7. Describe directory-based cache coherence and how it scales to many nodes.
8. How would you implement a read-repair mechanism for a distributed cache?
9. Compare Memcached's consistency model with Redis Cluster's.

## System Design
10. Design a multi-tier cache (L1: local, L2: distributed) for a social media feed service.
