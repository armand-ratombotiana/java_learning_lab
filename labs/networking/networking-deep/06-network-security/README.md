# Lab 06 — Network Security

## Overview
Deep dive into network security: firewalls, WAF, DDoS mitigation, IPS/IDS, network segmentation, and zero trust networking principles.

## Prerequisites
- Java 21+ development environment
- Basic network security concepts
- Familiarity with TCP/IP and HTTP

## What You Will Learn
- Implement packet filtering firewall with state tracking
- Build WAF rule engine for SQL injection and XSS detection
- Model DDoS mitigation strategies
- Implement IPS/IDS signature matching
- Design network segmentation with security zones
- Apply zero trust networking principles

## Topics Covered
| Topic | Description |
|-------|-------------|
| Firewalls | Stateful vs stateless, rule evaluation, default deny |
| WAF | OWASP rules, SQLi/XSS detection, rate limiting |
| DDoS Mitigation | SYN flood, UDP amplification, L7 DDoS, scrubbing |
| IPS/IDS | Signature detection, anomaly detection, alerting |
| Network Segmentation | VLAN, security zones, bastion hosts |
| Zero Trust | BeyondCorp, micro-segmentation, least privilege |
