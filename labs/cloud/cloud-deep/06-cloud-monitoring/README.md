# Lab 06 — Cloud Monitoring

## Overview
Deep dive into cloud observability: metrics, logs, traces, dashboards, alerts, anomaly detection, and distributed tracing with OpenTelemetry.

## Prerequisites
- Java 21+ development environment
- Basic monitoring and observability concepts
- Understanding of MTTD/MTTR

## What You Will Learn
- Implement metric collection and aggregation pipelines
- Build structured logging with context propagation
- Model distributed traces with spans and parent-child relationships
- Design dashboards and alert rules
- Implement anomaly detection algorithms
- Build an OpenTelemetry-compatible trace exporter

## Topics Covered
| Topic | Description |
|-------|-------------|
| Metrics | Counters, gauges, histograms, rate calculations |
| Logs | Structured logging, log levels, correlation IDs |
| Traces | Spans, trace context, sampling, propagation |
| Dashboards | Time-series visualization, threshold overlays |
| Alerts | Alert rules, severity, notification channels |
| Anomaly Detection | Statistical thresholds, z-score, moving averages |
| Distributed Tracing | OpenTelemetry SDK, exporters, sampling |
