# Lab 08 — Cloud Compliance

## Overview
Deep dive into cloud compliance frameworks: SOC 2, HIPAA, PCI DSS, GDPR, FedRAMP compliance controls, audit trails, data residency, and evidence collection.

## Prerequisites
- Java 21+ development environment
- Basic security and compliance concepts
- Cloud architecture familiarity

## What You Will Learn
- Implement compliance control frameworks in Java
- Build audit trail collection and tamper-evident logging
- Model data residency and sovereignty constraints
- Create evidence collection for compliance audits
- Design compliance monitoring dashboards

## Topics Covered
| Topic | Description |
|-------|-------------|
| SOC 2 | Trust service criteria, controls, auditor evidence |
| HIPAA | PHI handling, BAAs, security safeguards |
| PCI DSS | Cardholder data, CDE scope, SAQ requirements |
| GDPR | Data subject rights, DPA, DPO, breach notification |
| FedRAMP | NIST 800-53 controls, continuous monitoring |
| Audit Trails | Immutable logs, log integrity, chain of custody |
| Data Residency | Geographic constraints, data classification |
