# Lab 02 — Cloud Cost Optimization

## Overview
Deep dive into cloud financial management: reserved instances, spot instances, auto-scaling strategies, rightsizing, cost allocation tags, and FinOps practices.

## Prerequisites
- Java 21+ development environment
- Cloud computing fundamentals
- Basic understanding of cloud pricing models

## What You Will Learn
- Model reserved vs on-demand vs spot instance pricing in Java
- Implement auto-scaling policies based on cost and performance targets
- Build rightsizing recommendation engine
- Design cost allocation tag hierarchies
- Apply FinOps principles: visibility, allocation, optimization, governance

## Topics Covered
| Topic | Description |
|-------|-------------|
| Reserved Instances | 1-year/3-year RIs, convertibility, payment options |
| Spot Instances | Spot market pricing, interruption handling, spot fleets |
| Auto-Scaling | Dynamic scaling, scheduled scaling, predictive scaling |
| Rightsizing | Instance family selection, utilization analysis, recommendations |
| Cost Allocation Tags | Tag hierarchies, cost center mapping, chargeback/showback |
| FinOps | Iterative cost management, cross-team accountability |
