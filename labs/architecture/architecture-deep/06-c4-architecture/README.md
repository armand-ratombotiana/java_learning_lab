- C4 Model levels (Context, Container, Component, Code)
- System Context diagram
- Container diagram
- Component diagram
- Code (class-level) diagram

## Learning Objectives
- Create C4 diagrams as textual representations
- Understand the zoom-in hierarchy of C4
- Document architecture at each C4 level
- Relate C4 to code structure
