# Interview Questions — C4 Architecture Model

## Q1: What are the four levels of the C4 model?
**A:** Context (level 1 — system and actors), Container (level 2 — deployable units), Component (level 3 — logical modules), Code (level 4 — classes/interfaces).

## Q2: When would you stop at Level 2 vs going to Level 3?
**A:** Level 2 is sufficient for system-level discussions and deployment planning. Level 3 is needed when explaining how a container is internally structured, especially for onboarding new developers.

## Q3: What tools create C4 diagrams?
**A:** Structurizr (DSL-first), PlantUML C4 extension, draw.io, Mermaid, and manually via diagrams.net.
