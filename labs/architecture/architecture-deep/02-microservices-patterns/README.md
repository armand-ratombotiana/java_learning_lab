# Lab 02: Microservices Patterns

## Concepts Covered
- Decomposition (by business capability / subdomain)
- Database per Service
- API Gateway pattern
- Circuit Breaker
- Saga pattern (choreography & orchestration)
- Strangler Fig pattern

## Learning Objectives
- Decompose a monolith into bounded microservices
- Implement database-per-service isolation
- Build an API Gateway with routing
- Apply circuit breaker for resilience
- Coordinate distributed transactions with Saga
- Migrate incrementally using Strangler Fig
