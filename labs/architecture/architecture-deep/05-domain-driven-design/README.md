# Lab 05: Domain-Driven Design

## Concepts Covered
- Ubiquitous Language
- Bounded Context
- Aggregate
- Entity vs Value Object
- Domain Event
- Repository Pattern

## Learning Objectives
- Model a domain using ubiquitous language
- Define bounded contexts with clear boundaries
- Design aggregates with consistency boundaries
- Distinguish entities (identity) from value objects (attributes)
- Emit and handle domain events
- Implement repository pattern for aggregate persistence
