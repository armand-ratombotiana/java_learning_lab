# Lab 03: Hexagonal Architecture (Ports and Adapters)

## Concepts Covered
- Ports (inbound/outbound interfaces)
- Adapters (driving/driven)
- Adapter isolation
- Dependency Inversion Principle
- Application core without framework dependencies

## Learning Objectives
- Define inbound ports as use case interfaces
- Define outbound ports as repository/messaging interfaces
- Implement adapters (REST, console, persistence) that plug into ports
- Keep the domain core completely framework-free
