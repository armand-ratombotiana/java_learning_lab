# Lab 08: Serverless Architecture

## Concepts Covered
- Serverless patterns (e.g., SQS-Lambda-DynamoDB pipeline)
- Function composition (chaining, fan-out, fan-in)
- Event-driven serverless
- Cold starts (causes, mitigation)
- State management (externalizing to databases/caches)
- FaaS internals (execution environment, lifecycle)

## Learning Objectives
- Design a serverless data pipeline with function composition
- Handle cold starts with snap-start or keep-warm strategies
- Manage state externally with a key-value store
- Understand FaaS invocation lifecycle
