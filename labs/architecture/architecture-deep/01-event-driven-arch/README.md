# Lab 01: Event-Driven Architecture

## Concepts Covered
- Event Sourcing
- CQRS (Command Query Responsibility Segregation)
- Event Bus / Message Routing
- Event Versioning
- Idempotency

## Learning Objectives
- Implement an event-sourced aggregate root
- Build a CQRS pipeline separating commands and queries
- Create an in-memory event bus with routing
- Apply event versioning strategies for schema evolution
- Ensure idempotent event processing
