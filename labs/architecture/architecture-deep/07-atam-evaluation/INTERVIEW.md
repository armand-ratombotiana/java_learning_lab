# Interview Questions — ATAM

## Q1: What is the purpose of ATAM?
**A:** ATAM evaluates architectural decisions against quality attribute requirements and identifies tradeoffs, risks, and sensitivity points before implementation.

## Q2: What is a utility tree?
**A:** A hierarchical decomposition of "utility" into quality attributes (e.g., performance, availability) and their concrete scenarios with stimuli, responses, and measures.

## Q3: What is a tradeoff point?
**A:** An architectural decision that positively affects one quality attribute while negatively affecting another. Example: sharding improves scalability but hurts query simplicity.

## Q4: How does ATAM differ from a code review?
**A:** ATAM evaluates architecture-level decisions and quality attribute tradeoffs. Code review focuses on implementation correctness, style, and bugs within existing code.
