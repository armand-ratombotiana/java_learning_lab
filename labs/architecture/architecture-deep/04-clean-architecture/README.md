# Lab 04: Clean Architecture

## Concepts Covered
- Dependency Rule (inward-pointing dependencies)
- Entity layer (enterprise business rules)
- Use Case layer (application business rules)
- Presenter / Controller / Gateway boundary crossing
- Clean Architecture vs Hexagonal Architecture

## Learning Objectives
- Structure code in concentric layers (Entities → Use Cases → Interface Adapters → Frameworks)
- Cross boundaries using dependency inversion
- Compare Clean Architecture with Hexagonal Architecture
