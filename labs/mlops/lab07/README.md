# Lab 07: CI/CD for ML Pipelines

## Overview
Implement CI/CD pipelines for ML workflows using GitHub Actions and Jenkins. Learn automated model training, testing, validation, and deployment gates.

## Learning Objectives
- Design CI/CD pipelines for ML workflows
- Implement automated model training and validation
- Add quality gates (data validation, model evaluation)
- Deploy models to staging/production automatically

## Prerequisites
- Java 21+
- Git
- GitHub account (for Actions) or Jenkins
- Completion of labs 01-03 recommended
