# Company Interview Guide for MLOps Roles

## FAANG & Top Tech MLOps Interview Process

### Google — ML Engineer / MLOps
- **Phone Screen**: Coding (arrays, strings, trees) + ML fundamentals
- **On-site (5 rounds)**:
  1. ML Design (e.g., "Design a recommendation system")
  2. Coding (data structures & algorithms)
  3. System Design (e.g., "Design a feature store")
  4. ML Infrastructure (K8s, pipelines, monitoring)
  5. Googleyness (behavioral, leadership)
- **Focus**: Scale, distributed systems, data quality

### Meta — ML Engineer
- **Phone Screen**: Coding (medium/hard LeetCode)
- **On-site (4 rounds)**:
  1. Coding (2 rounds)
  2. ML Design (e.g., "Design News Feed ranking")
  3. Behavioral (Meta's principles: Move Fast, Be Open)
- **Focus**: Real-time inference, experimentation, A/B testing

### Amazon — ML Engineer / MLOps
- **Phone Screen**: Coding + ML basics
- **On-site (5 rounds)**:
  1. ML Design (e.g., "Design a fraud detection system")
  2. Coding (algorithms & data structures)
  3. System Design (distributed ML serving)
  4. Bar Raiser (behavioral, leadership principles)
  5. ML Depth (training, evaluation, scaling)
- **Focus**: AWS stack, cost optimization, operational excellence

### Apple — ML Engineer
- **Phone Screen**: Coding + ML fundamentals
- **On-site (6 rounds)**:
  1. ML Design
  2. Coding (2 rounds — algorithms + ML coding)
  3. System Design
  4. Behavioral + Manager
  5. Cross-functional
- **Focus**: On-device ML, privacy, model optimization

### Netflix — ML Platform Engineer
- **Phone Screen**: Deep ML infrastructure
- **On-site (5 rounds)**:
  1. System Design (ML platform)
  2. Coding (algorithms)
  3. ML Design (recommendations)
  4. Cultural Fit (Freedom & Responsibility)
  5. Manager round
- **Focus**: Chaos engineering, resilience, experimentation

### Microsoft — Applied ML Engineer
- **Phone Screen**: Coding + ML system design
- **On-site (4 rounds)**:
  1. ML Design + Coding
  2. System Design
  3. Behavioral + Azure fundamentals
  4. Hiring Manager
- **Focus**: Azure ML, responsible AI, MLOps maturity

## Interview Prep Checklist

### Coding (FAANG-level)
- [ ] Arrays & Hashing — 10 problems
- [ ] Sliding Window — 5 problems
- [ ] Trees & Graphs — 8 problems
- [ ] Heap / Priority Queue — 4 problems
- [ ] Dynamic Programming — 6 problems

### ML System Design
- [ ] Feature store design
- [ ] Model serving infrastructure
- [ ] ML pipeline orchestrator
- [ ] Monitoring & drift detection system
- [ ] A/B testing platform
- [ ] Distributed training infrastructure

### ML Fundamentals
- [ ] Supervised vs unsupervised learning
- [ ] Overfitting, regularization, bias-variance tradeoff
- [ ] Evaluation metrics (classification, regression, ranking)
- [ ] Feature engineering & selection
- [ ] Ensemble methods

### MLOps-Specific
- [ ] CI/CD for ML pipelines
- [ ] Containerization (Docker + K8s)
- [ ] Model versioning & registry
- [ ] Feature store (online/offline)
- [ ] Model monitoring & observability
- [ ] Infrastructure as Code (Terraform)
- [ ] Experiment tracking (MLflow)
