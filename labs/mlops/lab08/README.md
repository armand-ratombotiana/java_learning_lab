# Lab 08: Model Monitoring & Observability

## Overview
Implement model monitoring for drift detection, performance tracking, and alerting. Learn statistical drift detection methods and build a monitoring dashboard.

## Learning Objectives
- Detect data drift using statistical tests
- Monitor model performance metrics over time
- Set up alerting for drift and performance degradation
- Build a monitoring dashboard visualization

## Prerequisites
- Java 21+
- Statistics fundamentals (distributions, KL divergence)
- Completion of lab 05 recommended
