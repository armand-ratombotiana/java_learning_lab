# MLOPS Academy — Index

A hands-on curriculum for mastering MLOps with Java 21+.

## Labs

| # | Topic | Description |
|---|-------|-------------|
| 01 | ML Pipeline Orchestration | Airflow DAGs, pipeline-as-code concepts |
| 02 | Experiment Tracking with MLflow | Track experiments, parameters & metrics in Java |
| 03 | Model Registry & Versioning | Model version management, staging/promotion |
| 04 | Feature Store Architecture | Online/offline feature stores, feature serving |
| 05 | Model Serving with Docker | REST API serving with containerization |
| 06 | Kubernetes for ML | K8s deployment, scaling, rolling updates |
| 07 | CI/CD for ML Pipelines | GitHub Actions, Jenkins for ML workflows |
| 08 | Model Monitoring & Observability | Drift detection, performance monitoring |
| 09 | Data Validation & Quality | Great Expectations, schema validation |
| 10 | A/B Testing & Experimentation | Statistical significance, multi-armed bandit |
| 11 | Model Governance & Compliance | Audit trails, model cards, bias detection |
| 12 | Infrastructure as Code for ML | Terraform, Pulumi for ML infra |
| 13 | Distributed Training | Data/model parallelism concepts |
| 14 | AutoML Pipelines | Hyperparameter tuning, NAS |
| 15 | Production ML Architecture | End-to-end architecture design, case studies |

## Prerequisites

- Java 21+ SDK
- Maven or Gradle
- Docker & Docker Compose
- kubectl & minikube (for lab 06)
- Python 3.10+ (for Airflow, MLflow scripts)
- Terraform (for lab 12)
