# NeetCode Roadmap for MLOps Engineers

## Stage 1: Arrays & Hashing (Week 1)
- Contains Duplicate
- Valid Anagram
- Two Sum
- Group Anagrams
- Top K Frequent Elements
- Product of Array Except Self
- **MLOps Tie-in**: Feature vector operations, hash-based feature encoding

## Stage 2: Two Pointers (Week 2)
- Valid Palindrome
- 3Sum
- Container With Most Water
- **MLOps Tie-in**: Merge sorted model predictions, outlier detection

## Stage 3: Sliding Window (Week 3)
- Best Time to Buy and Sell Stock
- Longest Substring Without Repeating Characters
- Sliding Window Maximum
- **MLOps Tie-in**: Rolling window statistics, time-series feature engineering

## Stage 4: Binary Search (Week 4)
- Binary Search
- Find Minimum in Rotated Sorted Array
- Time-Based Key-Value Store
- **MLOps Tie-in**: Hyperparameter search, threshold optimization

## Stage 5: Trees & Graphs (Week 5)
- Invert Binary Tree
- Maximum Depth of Binary Tree
- Same Tree
- Number of Islands
- Clone Graph
- Course Schedule (Topological Sort)
- **MLOps Tie-in**: DAG pipeline resolution, decision trees, model topology

## Stage 6: Heap / Priority Queue (Week 6)
- Kth Largest Element
- Top K Frequent Elements
- Find Median from Data Stream
- **MLOps Tie-in**: Feature importance, online statistics

## Stage 7: Dynamic Programming (Week 7-8)
- Climbing Stairs
- House Robber
- Longest Increasing Subsequence
- Longest Common Subsequence
- **MLOps Tie-in**: Sequence modeling, time-series alignment

## Stage 8: ML-Specific Algorithms (Week 9-10)
- Matrix multiplication
- K-means clustering
- Nearest neighbors search
- Gradient descent implementation
- **MLOps Tie-in**: Core ML algorithm understanding

## Recommended Practice Schedule
- **Mon-Fri**: 1 LeetCode problem + reading one MLOps lab
- **Weekend**: System design practice + implement lab code
- **Weekly Review**: Revisit patterns, update notes

## Key Focus Areas for MLOps Interviews
1. HashMap/HashSet usage in feature engineering
2. Topological sort for pipeline DAGs
3. Heap for top-k and streaming statistics
4. Binary search for hyperparameter tuning
5. Dynamic programming for optimization problems
