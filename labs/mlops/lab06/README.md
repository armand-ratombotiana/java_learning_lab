# Lab 06: Kubernetes for ML

## Overview
Deploy ML models on Kubernetes. Learn about pod/deployment configuration, horizontal scaling, rolling updates, and resource management for ML workloads.

## Learning Objectives
- Create K8s deployments and services for ML models
- Configure Horizontal Pod Autoscaler (HPA)
- Implement rolling updates with zero downtime
- Resource requests/limits for ML workloads
- ConfigMaps and Secrets for model config

## Prerequisites
- Java 21+
- Docker Desktop with Kubernetes enabled (or minikube)
- kubectl installed
- Lab 05 Docker image
