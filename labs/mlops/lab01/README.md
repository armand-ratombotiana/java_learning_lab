# Lab 01: ML Pipeline Orchestration

## Overview
Learn how to design and implement ML pipeline orchestration using DAG-based workflows. Understand pipeline-as-code concepts, task dependencies, retry logic, and scheduling.

## Learning Objectives
- Understand DAG-based pipeline orchestration
- Design task dependencies with retry and alerting
- Implement a simulated ML pipeline in Java
- Map concepts to Airflow/Prefect/Dagster operators

## Prerequisites
- Java 21+
- Basic understanding of directed acyclic graphs (DAGs)
- Familiarity with Maven/Gradle
