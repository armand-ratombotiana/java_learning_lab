# Lab 02: Experiment Tracking with MLflow

## Overview
Learn to track ML experiments, log parameters, metrics, and artifacts programmatically using a Java client abstraction over MLflow's REST API.

## Learning Objectives
- Understand experiment tracking concepts
- Log parameters, metrics, and artifacts from Java
- Compare runs and visualize results
- Integrate tracking into a training pipeline

## Prerequisites
- Java 21+
- MLflow server (pip install mlflow)
- Basic ML concepts
