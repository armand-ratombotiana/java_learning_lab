# Lab 05: Model Serving with Docker

## Overview
Containerize a Java-based ML model serving REST API using Docker. Learn multi-stage builds, slim images, and production serving patterns.

## Learning Objectives
- Build and serve a model as a REST API
- Containerize the service with Docker
- Multi-stage Docker builds for slim images
- Health checks, graceful shutdown, resource limits

## Prerequisites
- Java 21+
- Docker & Docker Compose
- Basic HTTP/REST concepts
