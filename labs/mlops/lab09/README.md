# Lab 09: Data Validation & Quality

## Overview
Implement data validation pipelines for ML using schema validation, distribution checks, and quality metrics. Inspired by Great Expectations and Deequ.

## Learning Objectives
- Define data schemas and expectations
- Validate feature distributions and ranges
- Implement quality checks (null rates, uniqueness, bounds)
- Build a data validation report

## Prerequisites
- Java 21+
- Basic SQL knowledge
- Completion of lab 04 recommended
