# Lab 03: Model Registry & Versioning

## Overview
Learn to manage model versions, promote models through staging/production environments, and maintain model lineage using a simulated model registry in Java.

## Learning Objectives
- Understand model versioning strategies
- Implement staging, production, and archived model states
- Model lineage tracking (data → training → model)
- Champion/challenger pattern for model promotion

## Prerequisites
- Java 21+
- Completion of Lab 02 recommended
- Basic understanding of semantic versioning
