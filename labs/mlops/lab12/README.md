# Lab 12: Infrastructure as Code for ML

## Overview
Implement infrastructure as code (IaC) for ML infrastructure using Terraform and Pulumi concepts. Learn to provision ML infrastructure reproducibly.

## Learning Objectives
- Understand IaC principles for ML infrastructure
- Generate Terraform configurations programmatically
- Manage ML infrastructure state and changes
- Implement modular, reusable infrastructure components

## Prerequisites
- Java 21+
- Basic understanding of cloud resources (AWS/GCP/Azure)
- Terraform CLI (optional, for testing)
