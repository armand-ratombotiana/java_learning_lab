# Lab 11: Model Governance & Compliance

## Overview
Implement model governance practices including model cards, audit trails, bias detection, and compliance reporting for regulated ML deployments.

## Learning Objectives
- Create model cards documenting model purpose, limitations, and fairness
- Implement audit trails for model decisions
- Detect and measure bias across demographic groups
- Generate compliance reports

## Prerequisites
- Java 21+
- Basic understanding of fairness metrics
- Completion of lab 03 recommended
