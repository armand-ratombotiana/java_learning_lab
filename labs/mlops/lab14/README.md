# Lab 14: AutoML Pipelines

## Overview
Implement AutoML pipelines including hyperparameter tuning (grid search, random search, Bayesian optimization) and neural architecture search concepts.

## Learning Objectives
- Understand hyperparameter optimization techniques
- Implement grid search, random search, and Bayesian optimization
- Explore neural architecture search concepts
- Build an AutoML pipeline with parallel trials

## Prerequisites
- Java 21+
- Basic statistics (Gaussian processes conceptually)
- Multi-threading concepts
