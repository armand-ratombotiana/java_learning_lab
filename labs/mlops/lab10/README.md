# Lab 10: A/B Testing & Experimentation

## Overview
Implement A/B testing framework for ML models. Learn statistical significance testing, sample size calculation, and multi-armed bandit algorithms.

## Learning Objectives
- Design and run A/B experiments for model comparison
- Calculate statistical significance (p-value, confidence intervals)
- Implement multi-armed bandit (epsilon-greedy, UCB, Thompson sampling)
- Analyze experiment results and make data-driven decisions

## Prerequisites
- Java 21+
- Basic statistics (mean, variance, normal distribution)
- Completion of lab 03 recommended
