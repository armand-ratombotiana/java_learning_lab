# Lab 04: Feature Store Architecture

## Overview
Build an abstraction over an online/offline feature store. Learn to compute features in batch (offline) and serve them with low latency (online), with point-in-time correctness.

## Learning Objectives
- Understand online vs offline feature stores
- Implement feature computation and retrieval
- Point-in-time joins for training data
- Low-latency feature serving

## Prerequisites
- Java 21+
- Understanding of key-value stores
- Basic SQL knowledge
