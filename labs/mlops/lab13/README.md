# Lab 13: Distributed Training

## Overview
Understand distributed training concepts including data parallelism and model parallelism. Implement a simulation of distributed gradient computation using ring-allreduce.

## Learning Objectives
- Understand data parallelism vs model parallelism
- Implement distributed gradient aggregation (all-reduce)
- Simulate synchronous and asynchronous training
- Understand scaling efficiency and communication overhead

## Prerequisites
- Java 21+
- Basic understanding of neural networks and gradient descent
- Multi-threading concepts
