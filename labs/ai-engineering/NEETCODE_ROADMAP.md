# NeetCode Roadmap — AI Engineering Edition

## Stage 1: Arrays & Hashing (Week 1-2)
- `[E]` Contains Duplicate, Valid Anagram, Two Sum
- `[M]` Group Anagrams, Top K Frequent, Product of Array Except Self
- `[M]` Valid Sudoku, Longest Consecutive Sequence

## Stage 2: Two Pointers (Week 2-3)
- `[E]` Valid Palindrome, Two Sum II
- `[M]` 3Sum, Container With Most Water

## Stage 3: Sliding Window (Week 3-4)
- `[E]` Best Time to Buy and Sell Stock
- `[M]` Longest Substring Without Repeating, Longest Repeating Character Replacement
- `[H]` Minimum Window Substring, Sliding Window Maximum

## Stage 4: Stack & Queue (Week 4-5)
- `[E]` Valid Parentheses, Min Stack
- `[M]` Daily Temperatures, Evaluate Reverse Polish Notation
- `[H]` Largest Rectangle in Histogram

## Stage 5: Binary Search (Week 5-6)
- `[M]` Search in Rotated Sorted Array, Find Minimum in Rotated Sorted Array
- `[M]` Time Based Key-Value Store, Koko Eating Bananas

## Stage 6: Linked List (Week 6-7)
- `[E]` Reverse Linked List, Merge Two Sorted Lists
- `[M]` Reorder List, Remove Nth From End, Copy List with Random Pointer
- `[H]` Merge K Sorted Lists, Reverse Nodes in K-Group

## Stage 7: Trees (Week 7-8)
- `[E]` Invert Binary Tree, Max Depth, Same Tree, Subtree
- `[M]` Validate BST, Level Order, Construct from Pre/In-order, Kth Smallest
- `[H]` Serialize/Deserialize, Binary Tree Max Path Sum

## Stage 8: Tries (Week 8-9)
- `[M]` Implement Trie, Design Add and Search Words
- `[H]` Word Search II

## Stage 9: Backtracking (Week 9-10)
- `[M]` Subsets, Permutations, Combination Sum, Palindrome Partition
- `[H]` N-Queens

## Stage 10: Graphs (Week 10-12)
- `[M]` Number of Islands, Clone Graph, Pacific Atlantic Water Flow
- `[M]` Course Schedule, Graph Valid Tree, Number of Connected Components
- `[H]` Alien Dictionary, Word Ladder

## Stage 11: Dynamic Programming (Week 12-15)
- `[E]` Climbing Stairs, Min Cost Climbing Stairs
- `[M]` House Robber, Coin Change, Longest Increasing Subsequence
- `[M]` Palindromic Substrings, Longest Palindromic Substring
- `[H]` Edit Distance, Distinct Subsequences

## Stage 12: Intervals & Greedy (Week 15-16)
- `[M]` Insert Interval, Merge Intervals, Non-Overlapping Intervals
- `[M]` Jump Game, Jump Game II

## Stage 13: Advanced (Week 16-18)
- `[M]` Design Twitter, LRU Cache
- `[H]` Find Median from Data Stream, Largest Rectangle, Max Profit in Job Scheduling

## Stage 14: System Design (Ongoing)
- Design URL Shortener, Design Chat System
- Design LLM Serving Platform, Design RAG System
- Design Rate Limiter, Design Distributed Cache

## Weekly Schedule
- **Mon-Fri**: 2 LeetCode problems (morning + evening)
- **Weekend**: 1 system design problem + review weak areas
- **Daily**: 15 min reading AI engineering papers/blogs
- **Weekly**: Mock interview with peer or recorded self-practice
