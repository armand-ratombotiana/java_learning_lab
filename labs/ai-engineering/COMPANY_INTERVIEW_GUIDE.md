# Company Interview Guide

## FAANG Companies

### Google
- **Rounds**: Phone screen → 4-5 onsite (coding, ML design, Googleyness)
- **Focus**: Algorithms, system design, ML fundamentals, behavioral
- **AI-specific**: TensorFlow/JAX familiarity, transformer architecture, distributed training
- **Tips**: Emphasize scale (Google processes billions of queries). Know their AI products (Gemini, Search, YouTube).

### Meta
- **Rounds**: Phone screen → 4-5 onsite (coding, system design, behavioral)
- **Focus**: Coding speed (2 medium/hard in 45 min), practical system design
- **AI-specific**: Recommendation systems, ranking, real-time inference at scale
- **Tips**: Focus on practical implementation. Know PyTorch (Meta's framework). Discuss FAISS and vector search.

### Amazon
- **Rounds**: Phone screen → 4-5 onsite (coding, system design, LP bar raiser)
- **Focus**: Leadership principles, scalability, operational excellence
- **AI-specific**: SageMaker, Bedrock, personalization, fulfillment AI
- **Tips**: Every answer must reference Leadership Principles. Know Alexa and AWS AI services.

### Apple
- **Rounds**: Phone screen → 4-5 onsite (coding, system design, domain depth)
- **Focus**: Performance optimization, hardware-software co-design, privacy
- **AI-specific**: On-device ML, Core ML, privacy-preserving ML, Siri
- **Tips**: Emphasize low-latency, on-device inference. Discuss quantization and model compression.

### Netflix
- **Rounds**: Phone screen → 4-5 onsite (coding, system design, culture)
- **Focus**: Freedom and responsibility, high-performance culture
- **AI-specific**: Recommendation engine, content personalization, A/B testing
- **Tips**: Know their recommendation system architecture. Emphasize experimentation and data-driven decisions.

### Microsoft
- **Rounds**: Phone screen → 4-5 onsite (coding, system design, behavioral)
- **Focus**: Algorithmic depth, design breadth, collaboration
- **AI-specific**: Azure AI, Copilot, OpenAI partnership, M365 integration
- **Tips**: Know Azure AI services and how Copilot works under the hood.

## AI-Native Companies

### OpenAI
- **Rounds**: Phone screen → coding → research/engineering deep dive → cross-functional
- **Focus**: Deep ML expertise, production engineering, research understanding
- **AI-specific**: Transformer internals, RLHF, scaling laws, safety
- **Tips**: Read their papers (GPT-4, o1, DALL-E, Whisper). Know their API and safety practices.

### Anthropic
- **Rounds**: Technical screen → coding → system design → values fit
- **Focus**: Alignment, safety, interpretability, robust engineering
- **AI-specific**: Constitutional AI, RLHF, interpretability research
- **Tips**: Read their constitutional AI paper. Understand their focus on safety and interpretability.

### Cohere / Hugging Face / Mistral
- **Rounds**: Coding → ML depth → product sense
- **Focus**: Open-source ML, transformer expertise, developer experience
- **AI-specific**: Embedding models, fine-tuning, model serving
- **Tips**: Contribute to open-source. Know their specific models and APIs.
