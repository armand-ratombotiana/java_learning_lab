# AI Engineering Academy

A hands-on curriculum covering the full stack of AI engineering — from LLM serving infrastructure to production CI/CD.

## Labs

| # | Topic | Focus |
|---|-------|-------|
| 01 | [LLM Serving Infrastructure](lab01/README.md) | Model serving, batching, caching, load balancing |
| 02 | [Vector Database Integration](lab02/README.md) | Embedding storage, similarity search, indexing |
| 03 | [RAG System Architecture](lab03/README.md) | Retrieval pipeline, chunking, hybrid search |
| 04 | [AI Agent Frameworks](lab04/README.md) | ReAct patterns, tool use, multi-agent orchestration |
| 05 | [Prompt Engineering at Scale](lab05/README.md) | Template management, versioning, A/B testing |
| 06 | [AI Pipeline Orchestration](lab06/README.md) | Preprocessing, feature extraction, inference, post-processing |
| 07 | [AI Testing & Evaluation](lab07/README.md) | Unit tests for AI, regression, benchmark automation |
| 08 | [AI Observability](lab08/README.md) | Token tracking, latency, cost, drift detection |
| 09 | [AI Security](lab09/README.md) | Prompt injection, data leakage, access control |
| 10 | [AI Deployment & CI/CD](lab10/README.md) | Model deployment, canary, rollback, blue-green |
