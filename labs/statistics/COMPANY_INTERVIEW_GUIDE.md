# Company Interview Guide — Statistics

How each company typically tests statistics knowledge.

| Company | Focus Area | Typical Questions |
|---------|------------|-------------------|
| Google | A/B testing, causal inference | "Design an experiment for a new search feature" |
| Meta | Hypothesis testing, metrics | "How would you measure engagement changes?" |
| Amazon | Business metrics, forecasting | "Forecast demand for a new product category" |
| Microsoft | Experimental design, regression | "How do you control for confounding variables?" |
| Uber | Time series, geospatial stats | "Model surge pricing with causal inference" |
| Airbnb | A/B testing, mixed models | "Handle carryover effects in vacation experiments" |
| Netflix | Recommendation stats, bandits | "Design a multi-armed bandit for content selection" |
| Apple | Quality metrics, reliability | "Test whether a new iOS version improves battery life" |
| LinkedIn | Network effects, random effects | "Account for social network interference in experiments" |
| Spotify | User behavior, longitudinal data | "Model user retention with repeated measures" |

## Common Company-Specific Frameworks

- **Google**: Use the "Trustworthy Online Controlled Experiments" framework
- **Meta**: Apply the "Variance Reduction" techniques (CUPED)
- **Netflix**: Focus on "innovation tournaments" and sequential testing
- **Amazon**: Use "flywheel metrics" with long-term holdout groups
