# Lab 07: SRE Practices

## Concepts Covered
- SLO (Service Level Objective), SLI (Service Level Indicator), SLA (Service Level Agreement)
- Error budgets (calculation, burn rate, policy enforcement)
- Toil automation (identifying, measuring, eliminating toil)
- Incident response (SRE principles)
- Postmortems (blameless, action items)
- Reliability engineering practices

## Learning Objectives
- Define SLIs and SLOs for a service
- Calculate and manage error budgets
- Automate toil with runbooks and scripts
- Conduct blameless postmortems
- Implement reliability improvements based on data
