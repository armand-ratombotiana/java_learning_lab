# Lab 04: Secret Management

## Concepts Covered
- HashiCorp Vault (dynamic secrets, leasing, revocation)
- Kubernetes Secrets (limitations, etcd encryption)
- External Secrets Operator (sync from Vault/AWS/GCP to K8s)
- Encryption in transit vs at rest
- Secret rotation strategies

## Learning Objectives
- Store and retrieve secrets from Vault
- Understand Kubernetes Secret limitations
- Sync external secrets using operator patterns
- Implement encryption in transit (TLS) and at rest (AES-256)
- Automate secret rotation
