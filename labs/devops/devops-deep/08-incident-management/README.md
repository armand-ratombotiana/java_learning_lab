# Lab 08: Incident Management

## Concepts Covered
- Incident severity levels (SEV1-SEV4)
- Escalation paths and timelines
- Incident Commander model (IC, Deputy, Scribe, SME)
- Communication (status updates, stakeholder notification)
- Root Cause Analysis (RCA)
- Blameless culture

## Learning Objectives
- Classify incidents by severity
- Implement the Incident Commander model
- Run effective incident response communication
- Conduct blameless RCAs
- Apply post-incident improvements
