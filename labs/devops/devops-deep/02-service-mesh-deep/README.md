# Lab 02: Service Mesh Deep Dive

## Concepts Covered
- Istio architecture (control plane vs data plane)
- Envoy proxy sidecar injection
- mTLS (mutual TLS) between services
- Traffic splitting (canary, blue/green)
- Observability (metrics, tracing, access logs)
- Fault injection and circuit breaking

## Learning Objectives
- Deploy Istio with Envoy sidecars
- Enable mTLS for mesh-wide security
- Configure traffic splitting rules
- Implement fault injection for resilience testing
- Set up circuit breakers for fault isolation
