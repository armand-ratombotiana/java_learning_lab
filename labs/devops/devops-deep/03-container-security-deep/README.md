# Lab 03: Container Security Deep Dive

## Concepts Covered
- Image scanning (vulnerability scanning, SBOM)
- Dockerfile best practices (multi-stage builds, minimal base images)
- Rootless containers
- Seccomp (secure computing mode) profiles
- AppArmor (mandatory access control)
- Runtime security with Falco

## Learning Objectives
- Scan container images for vulnerabilities
- Write secure Dockerfiles following best practices
- Run containers without root privileges
- Apply seccomp profiles to restrict syscalls
- Configure AppArmor profiles
- Detect runtime threats using Falco rule simulation
