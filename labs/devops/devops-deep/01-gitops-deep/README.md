# Lab 01: GitOps Deep Dive

## Concepts Covered
- GitOps principles (declarative, versioned, automated)
- ArgoCD vs Flux
- Declarative configuration (Kubernetes manifests, Helm, Kustomize)
- Drift detection and remediation
- Sync strategies (automatic, manual, phased)

## Learning Objectives
- Understand GitOps as the single source of truth
- Compare ArgoCD and Flux architectures
- Implement drift detection with reconciliation loops
- Apply sync strategies for safe deployments
