# Lab 06: Canary Deployments

## Concepts Covered
- Canary releases (gradual traffic shifting)
- Traffic shifting strategies (weighted, header-based, cookie-based)
- Metrics-based rollback
- Progressive delivery
- Argo Rollouts (blue-green, canary strategies)

## Learning Objectives
- Implement a canary deployment with weighted traffic splitting
- Define metrics-based promotion/rollback gates
- Automate progressive delivery using Argo Rollouts concepts
- Monitor and rollback on error rate spikes
