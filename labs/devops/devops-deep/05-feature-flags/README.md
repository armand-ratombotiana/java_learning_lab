# Lab 05: Feature Flags

## Concepts Covered
- Feature flag patterns (release toggles, experiment toggles, ops toggles, permission toggles)
- LaunchDarkly concepts (flag keys, targeting rules, variation)
- A/B testing via feature flags
- Flag lifecycle management (creation, evaluation, retirement)

## Learning Objectives
- Implement a feature flag evaluation engine
- Apply targeting rules (user segments, percentage rollouts)
- Run A/B test experiments with flag variations
- Manage flag lifecycle from creation to retirement
